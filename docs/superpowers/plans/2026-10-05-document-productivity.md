# 구현 순서

1. 수정 이력 비교: stable ID 기준 변경 목록, 과거 미리보기 유지, 복원은 새 버전.
2. 페이지 연결: 기존 페이지 추천과 owner-only 역링크 SQL 색인, 편집기에 통합.
3. 메모/오프라인: 대기 영수증 안내, 기기 보관 상세, 동기화 상태 설명.
4. URL 북마크: 수집기 보안 재사용 → 메타데이터/이미지 제한 테스트 → 저장 검증·검색·Markdown·공유 → 카드와 붙여넣기 선택 UI.
5. 통합: 전체 테스트/빌드, 임시 DB 브라우저 기능 시나리오와 PC/모바일 화면 확인, 현재 구현 문서 갱신.

각 작업은 기존 파일의 책임을 나눠 수행하고 저장 계약을 변경하지 않는다. 실제 데이터 seed·커밋·배포는 이 작업에 포함되지 않는다.
