# 할 일 첫 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 홈 오른쪽 투두와 전체 보기에서 할 일을 직접 추가·수정·완료·되돌릴 수 있게 한다.

**Architecture:** Node SQLite 저장 모듈과 개인용 API를 추가한다. 작은 React TaskWorkspace가 홈 패널과 전체 보기를 제공하고 기존 셸에 연결한다. 메모·페이지·AI는 할 일 저장에 의존하지 않는다.

**Tech Stack:** 기존 React 19·TypeScript·Vite 6·Node 24·SQLite·Playwright. 신규 의존성 없음.

**Spec:** `docs/superpowers/specs/2026-09-28-task-workspace-design.md`. 현재 사용자가 승인한 첫 범위는 직접 추가·수정·완료·전체 보기다. 출처 가져오기·AI는 이후 단계다.

## Global Constraints

- 사용자 지정 현재 디렉터리에서 진행하고 기존 미커밋 작업을 보존한다. 작업을 임의로 커밋하지 않는다.
- 실제 `data/`는 테스트에 사용하지 않는다. Task 테이블과 목록 변경 번호를 위한 작은 메타 테이블·트리거를 기존 DB에 추가한다.
- 제목 500자, 날짜는 한국 기준 `YYYY-MM-DD`, 일반 시각은 UTC ISO. 상태는 `open`·`done`이다.
- 수정은 `expectedVersion`으로 검사하며 충돌 응답에 최신 항목을 돌려준다.
- 홈은 PC 5개, 모바일 3개를 먼저 표시한다. 1160px 이하에서는 입력 다음에 표시한다.
- 신규 AI·블록 편집기 의존성을 입력함에 추가하지 않는다.

## Review Focus

- 빠른 연속 체크: 마지막 선택이 저장되고 늦은 응답이 뒤집지 않아야 한다.
- 저장 실패: 화면 상태 복원과 재시도가 가능하고 제목 초안이 남아야 한다.
- 날짜: 윤년·잘못된 날짜를 검사하고 기한이 없는 항목에 오늘 표시를 만들지 않는다.
- 많은 작업: 홈 개수 제한이 전체 보기 누락으로 이어지지 않아야 한다.
- 다른 탭의 수정: 서버 최신 상태를 덮지 않고 편집 초안을 유지해야 한다.
