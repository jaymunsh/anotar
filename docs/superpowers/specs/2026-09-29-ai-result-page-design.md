# AI 결과를 편집 가능한 페이지로 정리

## 의도

AI 요청 결과를 한 문서로 정리하고 바로 편집한다. 제목·목록·표·코드·Mermaid·출처가 Markdown 의미대로 블록이 되고, 페이지 전체는 하나의 Markdown으로 보기·복사할 수 있다. 페이지 원본 저장 형식은 기존 `schemaVersion: 1` 블록 JSON이다.

## 기존 흐름 확장

- AI 결과에 **결과를 페이지로 정리**를 추가한다. 선택한 완료 작업의 결과를 사용한다. 기본은 새 페이지이며 기존 페이지나 특정 상위의 새 하위 페이지도 선택한다.
- 내용과 별도의 출처 목록을 함께 변환한다. 새 문서는 맨 앞 H1을 제목으로 제안하고 같은 제목을 본문에 반복하지 않는다. 기존 문서에 추가하면 해당 H1도 본문에 유지한다.
- `CapturePageImport`와 기존 API를 재사용한다. 제출 전 Markdown parser만 지연 로드하고 새로운 서버 패키지·에디터 번들은 첫 입력 화면에 포함하지 않는다.
- 가져오기 선택은 `aiResult: { jobId, document }`를 선택적으로 확장한다. 서버는 소유 Capture·완료 상태와 블록 문서·안전한 링크·1MB/1,000블록 상한을 검사한다. AI 변환 블록에는 개인 파일·메모·페이지 참조를 넣지 않는다. 원본 참조는 서버가 별도로 만든다.
- 제출 사본에 작업 ID·변환 문서·대상·UUID를 보존한다. 원자적 문서 쓰기/참조/작업 영수증과 응답 유실 후 중복 방지를 유지한다. 새 UUID로 같은 결과를 명시적으로 다시 가져올 때에는 새 블록 ID를 만든다.
- 원문과 AI 결과·요청 사본은 그대로 남는다. 페이지 수정이 결과나 원문으로 역전파되지 않는다. AI 호출이나 자동 할 일 등록은 추가하지 않는다.

## 문구

- `현재 내용으로 요청` → **현재 메모로 다시 요청**. 보관 당시 템플릿 사본과 추가 지시를 재사용하고 메모 입력만 최신 저장본으로 조립한다.
- 실패의 `같은 요청 재시도` → **실패한 요청 그대로 재시도**. 이전 입력·템플릿·추가 지시를 그대로 재사용한다.
- `보관한 요청문` → **요청 당시 입력·프롬프트**. 선택한 작업의 입력과 요청문을 보여주는 조회 영역이다.
- 실행기와 모델은 실제 작업 기록으로 명시한다. Devin 호출의 모델 선택 방식·기본값·사용량은 변경하지 않는다.

## 검증

임시 DB 단위 테스트: 완료 작업 선택, 다른 메모/미완료 거절, 반복 제출/재시작, 원문/결과 보존, 문서 상한·위험 링크·참조 차단과 원자적 롤백. 실제 브라우저/임시 실행기 QA: Markdown 구조·표·Mermaid·편집·다시 열기·전체 Markdown 복사·출처·응답 유실/복구, PC/320·390px와 밝음/어두움. 기존 저장소 전체 테스트와 빌드도 통과해야 한다. 실제 `data/`와 유료 제공자는 검증에서 사용하지 않는다.
