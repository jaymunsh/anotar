# 서버 이전 전 완성 설계

## 목적과 승인 범위
개인용 leneu의 수집 → 메모 → 페이지/일정 → 읽기 공유 흐름을 완성한다. 사용자가 전체 마무리를 요청한 범위에서 공유 댓글 받은함, 모바일 수집, 일정·할 일 연결, Docker/복원 준비를 진행한다. 실제 서버 접속·DNS·TLS·기기 재부팅은 대상 환경에서 남는다.

## 보존과 경계
기존 사용자 DB/첨부/초안/페이지를 덮거나 초기화하지 않는다. 실제 AI/OCR 호출 없이 fixture로 검증한다. SQLite와 현재 block JSON schemaVersion 1을 유지하고 개인 API는 루프백/Tailscale 전용이다. 공개 서버는 읽기 DB와 제한된 댓글 broker만 사용한다. 홈/공개에 무거운 편집기·지도 SDK를 추가하지 않는다.

## 1. 공유 댓글 받은함
개인 `/comments`에 페이지를 넘나드는 공유 대화를 최근 방문자 메시지 순으로 나열한다. 새 댓글(읽지 않은 방문자 메시지)과 미해결/해결 상태를 분리한다. 가벼운 홈 카드에서 미확인·미해결 수와 최근 대화를 표시한다. 대화를 열면 해당 페이지의 공유 댓글 패널/블록으로 이동한다. 읽음 처리는 확인한 마지막 방문자 메시지 ID까지만 기록해 동시에 도착한 메시지를 놓치지 않는다. 개인 댓글은 포함하지 않으며 삭제/휴지통 페이지는 제외한다. 조회는 제한된 페이지 단위 SQL+인덱스이며 전체 문서를 홈에서 읽지 않는다.

## 2. 모바일 수집
기존 빠른 입력을 유지하고 붙여넣은 URL 자동 인식, 파일 첨부, 작은 화면과 키보드 동선을 강화한다. 설치용 manifest와 공유 진입점 `/capture`를 제공한다. 지원 환경의 OS 공유 대상은 임시 첨부를 내구성 있게 보관한 뒤 사용자가 확인/저장한다. 기존 초안을 덮지 않고 가져오기/취소 선택을 제공한다. 지원하지 않는 Safari/iOS에서는 홈 화면 추가와 URL/이미지 복붙 동선으로 안내한다. 오프라인 서버 저장 성공을 가장하지 않는다. 공개 공유 서비스에는 PWA 수집/업로드 경로가 없다.

## 3. 일정·할 일 연결
일정 항목별 준비 할 일과 관련 페이지/메모를 연결한다. 연결 정보는 개인 데이터이며 기존 일정 JSON/공개 렌더링에 사적인 ID를 흘리지 않는다. 현재 저장된 페이지/블록/항목을 서버에서 확인한다. 할 일 상태는 기존 Task의 단일 원본을 쓴다. 공유 시에는 사용자가 명시적으로 선택한 할 일 제목/상태만 현재 페이지의 공유 읽기 화면과 ZIP에 표시한다. 개인 메모/페이지 내용이나 관계의 원본 ID는 공개하지 않는다. 삭제·휴지통·블록 삭제·낡은 버전·중복 재전송을 처리한다.

## 4. 이전 준비
실제 Docker 환경에서 private/public 분리, 댓글 socket, 링크 폐기, 재시작 후 데이터 유지, 백업 검증·새 경로 복원을 시험한다. production 이미지에 backup CLI도 포함한다. 데이터/백업 볼륨과 포트는 환경으로 설정 가능하고 `.env.example`에는 비밀 없는 값만 둔다. 복원은 빈 새 경로에만 한다. Ubuntu/N100 이전 명령·Tailscale 개인/Tunnel 공유·DNS·TLS·외부 백업·재부팅 체크를 문서화한다. 로컬 Docker 결과를 N100 측정으로 주장하지 않는다.
