# 메모 관리와 AI 요청 구분

사용자 요청: 보관한 항목을 `/memo`에서 관리하고 AI 요청은 별도로 노출한다. 실제 저장된 이해하기 쉬운 예시를 제공한다. 기존 색감·짧은 목록·빠른 입력·개인 문서 편집을 유지한다.

## 화면과 주소

- `/`: 빠른 입력·할 일·최근 일반 메모 3개. 목록 필터와 검색은 `/memo`에서 한다.
- `/memo`: 보관한 메모 관리. 기본 **메모**, 별도 **AI 요청** 탭을 둔다. AI 탭 직접 주소는 `/memo?view=ai`. 사용자가 별도 메뉴를 선호하면 같은 저장·목록을 메뉴로 연결한다.
- `/pages/:id`: 일반 블록 문서. `/pages`와 `/temp` 이전 진입 주소는 `/memo`로 연결한다. 기존 임시 문서는 일반 페이지로 보존하고 새 임시 문서를 자동 생성하지 않는다.
- 메모 관리도 공통 셸 안에서 전환한다. 홈의 텍스트·첨부·AI 설정 초안은 유지하며 모바일 빠른 기록 버튼을 쓴다.
- 종류 필터·검색·상세·명시적 수정·버전 충돌 보존을 재사용한다. 목록은 기존 최대 100개이며 상한에 도달하면 최근 100개임을 표시한다.

## AI 요청 보관

AI 선택 시 Capture 원본에 nullable `ai_request` JSON을 연결한다. 이는 실행 기록이나 작업 큐가 아니라 **보관 시점의 요청문**이다. 외부 URL 수집·AI 호출·자동 결과 생성은 없다.

- 입력: `aiRequest: {template: PromptTemplate | null, additional: string}`. 템플릿 사본은 사용자가 미리보기에서 확인한 버전을 쓴다.
- 서버가 저장 원문의 URL·텍스트로 요청문을 조립한다. 현재 1회 변수 치환·URL 추론·직접 요청 규칙을 공통 함수로 재사용한다.
- 저장값: `schemaVersion: 1`, `status: prepared`, 템플릿 ID·이름·버전·수정본·본문, 종류, 추가 요청, 당시 입력, 조립된 요청문. 추가 요청 1,000자·템플릿 본문 10,000자·조립 요청문 64,000자까지 검증한다.
- 원본·첨부 메타데이터·요청문은 한 트랜잭션에서 저장한다. 잘못된 요청 JSON을 일반 메모로 조용히 저장하지 않는다. 원본 수정은 보관된 요청문을 재작성하지 않는다.
- API의 `scope=all|memo|ai`는 LIMIT 전에 적용한다. 기본 `all`은 기존 API와 호환한다. 별도 전체 개수 `{memo, ai}`를 제공한다. AI 검색에는 당시 입력·템플릿 이름·요청문을 포함한다.
- 목록과 상세는 **실행 전**을 표시한다. 상세에서 보관된 요청문을 읽고 복사할 수 있다. 원본 수정과 요청문 사본의 관계를 안내한다.

## 샘플

일반 메모·외부 문서 링크·실제 PNG 여행 메모·Markdown 체크리스트 첨부 4개, URL 리서치와 여행 계획의 실행 전 요청문 2개, 정리된 여행 문서와 하위 교통·예약 체크 블록 페이지 2개, 독립 Task 2개를 만든다. 시드 항목도 일반 메모처럼 관리하며 목록·상세에 예시 표시를 붙이지 않는다. AI 실행이나 결과 생성을 하지 않는다.

Capture의 `sample_key`는 스크립트의 중복 방지용이며 API에는 `isSample`만 제공하되 별도 시드 표시를 렌더링하지 않는다. 같은 키 재실행은 기존 항목을 돌려주며 사용자가 수정한 내용을 덮지 않는다. 페이지는 `page_roles`의 `sample.*` 키로 찾아 생성하고 이름을 바꾸거나 수정한 페이지를 덮지 않는다. Task는 고정 `requestId`로 기존 항목을 찾아 수정한 제목·상태를 유지하며 페이지 체크리스트와 자동 연결하지 않는다. 첨부 바이트는 실제 파일 저장소에 저장한다. 자동 시작 시에는 샘플을 생성하지 않는다.

## 검증

임시 DB에서 기존 메모의 이관·요청문 보존·목록 구분·검색·잘못된 설정 거절·첨부 실패 롤백·샘플 재실행을 확인한다. Chrome에서 `/memo` 직접 진입·탭 주소·뒤로 가기·새로고침·상세 수정·초안 유지·AI 미실행·320/390px·라이트/다크를 검사한다. 페이지의 Markdown·Mermaid·저장·충돌 검증은 유지한다.
