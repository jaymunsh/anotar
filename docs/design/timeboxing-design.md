# 타임박싱 일지 예시

[미리보기](timeboxing-preview.html) · http://127.0.0.1:5173/docs/design/timeboxing-preview.html

## 현재 방향

사용자 PDF의 핵심 할 일·생각·아이디어·회고·24시간 표를 참고했다. 최신 요청에 따라 실제 기록 열을 제거하고 계획 한 열만 표시한다. 기존 연속 일지 예시는 수정하지 않는다. anotar `/journal` 메뉴에 같은 화면 코드를 연결했다. 서버 저장·동기화는 아직 연결하지 않았다.

## 일간 화면

- 제목은 `2026년 10월 5일 월요일`처럼 전체 날짜다. 상단 달력에는 타임박싱 계획·핵심 할 일·메모를 작성한 날짜만 점으로 표시한다. 달력 아래 설명/범례는 없다. 과거 실제 기록만 있는 날짜는 표시하지 않는다.
- 용지 최대1280px. PC 상단 오른쪽 달력210px, 본문은 메모와 계획표 약28:72 비율이다. 모바일은 상단 달력 → 시간표 → 메모 순서다.
- 00–24시를 한 시간씩24행으로 표시한다. 왼쪽 시간과 시간 헤더는 가로·세로 중앙 정렬이다. 각 시간 행의 여섯 칸은10분이다. 상단 분 눈금은 PC00/10/20/30/40/50/60, 모바일00/30/60이다.
- 일정은 각 시간 행과 겹치는 칸을 차지한다. 여러 시간에 걸치면 행마다 이어지며, 종류별 색칠 없이 같은 옅은 면을 사용한다. 점유 이중선은 없다. 짧은 칸의 제목은 말줄임된다. 전체 내용·시작·종료는 hover 설명 또는 클릭한 상세 수정창에서 확인한다.
- PC 일정 hover/키보드 focus에서 같은 행 오른쪽 끝에 상세 보기와 × 미이행 액션을 표시한다. 미이행은 테마별 붉은 배경/글자와 취소선으로 보이며 다시 해제할 수 있다. 모바일은 일정 클릭 후 상세창의 미이행 체크로 조작한다. 삭제와 미이행은 다른 동작이다.
- 목록 보기는 전체 제목과 시간 범위를 제공하며 미이행도 취소선으로 표시한다. 새 일정은 클릭한10분 칸부터30분이다. 시작/종료는10분 단위이며 같은 열의 겹침은 거절한다. 종료00:00은 다음 날24:00이다. 기존 항목 편집은 원래 길이를 유지하고 종료 직접 수정 후에는 자동 조정을 멈춘다.
- 메모는12px(모바일16px), 제목13px(모바일14px). 내용에 맞춰 최대600px까지 늘어나고 더 길면 내부 스크롤한다. 모바일 시간표 대상 높이44px, 가로 넘침 없이 전체 계획 열을 표시한다.

## 되짚어보기 및 요약

`되짚어보기`는 전체 저장 날짜에서 직접 미이행 표시한 계획만 모은다. 최신 날짜순, 같은 날짜 안은 시작 시간순이다. 날짜와 항목의 시간/제목을 표시하며 클릭하면 해당 날짜의 상세창을 연다. 표시하지 않은 항목을 완료로 추정하지 않는다. 표시를 해제하거나 계획을 삭제하면 모음에서 빠진다.

주간·월간은 계획 시간·미이행 개수와 기존 핵심 할 일/메모/회고를 요약한다. 과거 실제 기록은 표시하거나 합계에 반영하지 않는다. 주간은 월요일 시작, 월간은 해당 월 날짜만 포함한다. 자동 AI 해석이나 타이머는 없다.

## 저장과 파일

전용 `anotar:timeboxing-design:v1` localStorage만 사용한다. `plan[].missed`는 선택적 boolean이며 기존 자료에 없으면 미표시다. 기존 실제 기록·유형·짧은메모 값은 보존한다. 일반 항목 수정에서도 미이행 값이 보존된다. 저장에 실패하면 미이행 표시를 바꾸지 않고 오류를 보여준다. 스키마 오류 시 원본을 덮어쓰지 않는다. 실제 제품 자료를 수정하지 않는다.

- `timeboxing-preview.html`: 구조·상세창·되짚어보기 영역.
- `timeboxing-preview.css`: 기존 paper/forest 테마, 반응형 배치·시간표·hover 액션.
- `timeboxing-preview.mjs`: 공통 컨트롤러를 예시 모드로 실행하는 진입점.
- `src/journal/controller.mjs`: 날짜·입력·미이행·되짚어보기·브라우저 저장 공통 로직.
- `src/journal/JournalWorkspace.tsx`: 실제 앱 메뉴의 Shadow DOM 마운트·테마 상속·정리. HTML/CSS는 예시와 공유하며 iframe을 사용하지 않는다.
- `timeboxing-model.mjs`: 기존 날짜/기간/시간 합계 함수. 화면에서는 실제 기록을 제외한 사본으로 요약한다.

## anotar 메뉴 연결

메뉴 순서는 검색 → 메모 → 일지 → 할 일 → AI 작업 → 공유 댓글이다. `/journal`은 한국시간의 오늘, 빈 기록으로 시작하며 `anotar:journal:v1`에만 저장한다. 예시의 고정 날짜·가상 자료·`anotar:timeboxing-design:v1`은 섞지 않는다. 상단/하단에 기기 저장·서버 미연결 상태를 표시한다. 서버 동기화/백업/기기간 공유와 연결되지 않았으므로 다른 기기나 브라우저에서는 같은 일지가 보이지 않는다.

상세·× 액션은 테두리 패널 없이 오른쪽에 작은 글자로 표시하며 미이행 제목 앞 ×는 제거했다. 두 테마의 붉은색/취소선은 유지한다. 앱 전체 테마를 상속한다. 마운트 해제 시 resize/beforeunload/media listener와 테마 observer를 정리한다. 다른 탭에서 저장 내용이 바뀌었으면 덮어쓰지 않고 오류를 알린다.

검증: `.omo/evidence/journal-integration/verification.json`. 빌드 및 TypeScript 확인 통과. 실제 휴대폰/PWA 설치 후 오프라인 실행·서버 저장은 이번 검증에 포함하지 않는다.

## 후속 화면 정돈 (2026-10-05)

- 할 일은 빈3개 기본이며0–20개 추가/삭제 가능하다. 삭제 직후 같은 날짜에서 최근 삭제1건을 되돌릴 수 있다. 기존 사용자 편집내용은 유지하며 미편집 최초 예시3개만 비운다.
- 액션은 같은11px 글자, 투명 배경, 얇은 테두리다. 붙은 일정 사이에는 세로 구분선이 있다. 미이행 일정의 붉은색은 유지하되 액션에는 붉은 글자를 쓰지 않는다.
- 팝업 최대460px·안쪽20px(모바일18px), 시간2열, 설명이 붙은 미이행 스위치다. 앱 CSS 스코프가 `.dialog-body`를 훼손하던 정규식을 고쳤다.
- 끝 눈금은60만 표시한다. 시간표 하단 안내/중복 추가 버튼·푸터는 제거하고 저장 상태는 날짜 제목 아래로 옮겼다.
- 메모 순서는 아이디어 → 하루 돌아보기 → 머릿속 생각(Brain Dump). PC 메모3개는 시간표 높이에 맞춰 분배되고 모바일은 내용 높이다. 모바일 달력은 본문 전체 폭이다.
- 검증: `.omo/evidence/journal-polish/verification.json`. 프리뷰·실제 앱 모두 추가/삭제/되돌리기/새로고침/팝업 여백/미이행/달력 정렬 확인.

### 드래그·모눈 (2026-10-05)

PC 마우스/펜으로 일정 가운데를 드래그하면 길이를 유지하며 이동하고 처음/마지막 조각의 양 끝7px 핸들로 시작/종료를 조절한다. 다른 시간 행으로 옮길 수도 있다. 10분 반올림·최소10분·당일00–24시 제한이다. 6px 이하 움직임은 클릭이다. 드래그 미리보기/시간을 표시하고 겹침이면 붉은 미리보기, 놓으면 원래 자료를 유지한다. Escape·pointercancel·스크롤·화면 resize·언마운트는 취소한다. 저장 성공 후에만 원본에 반영하며 드래그 직후 클릭은 상세창을 열지 않는다. 터치는 스크롤을 유지하고 상세창 입력으로 조절한다. 자동 스크롤은 없다.

상세 보기 버튼은 제거하고 오른쪽 안쪽에 붉은 ×만 표시한다. 미이행 상태는 aria-pressed 및 기존 색/취소선으로 구분하며 같은 버튼으로 해제한다. 일정 전체1px 테두리·hover/focus 진한 테두리와 resize 핸들을 제공한다. 메모에는12px 모눈을 테마별 낮은 대비로 적용한다. 시간표는 중첩을 피하기 위해 별도 모눈을 제거하고 시간 경계선과10분 세로선만 사용한다. 상단 분 눈금은 별도 띠와 작은 눈금 막대로 구분한다. 할 일은 고정 체크/번호 열과 공통 텍스트 시작선을 쓰고 안내문은 `할 일 입력`이다.

순수 시간 계산은 `src/journal/dragTime.mjs`. 검증 `.omo/evidence/journal-drag/model.test.mjs` 및 `check.mjs`: 이동/양쪽 resize/다른 시간 행 왕복/Escape/겹침 거절/클릭/새로고침/번호 정렬/테마/모바일.
