# 연간·분기 계획표와 할 일 연결 제안

2026-10-13. 기본 연간·분기 계획표와 할 일 연결은 로컬에 구현했다. 현재 범위는 PLANNING_BOARDS.md를 따른다. 아래 내용의 결과 수치·이동 이력 등은 후속 제안이다.

## 개념 분리

- 시간표: 언제 무엇을 할지 배치한다. 시간 배치만으로 장기 작업이 완료되지는 않는다. 별도의 실제 시간 기록은 현재 일지 UI에서 사용하지 않는다.
- 할 일: 사용자가 할 일·진행 중·끝냄을 직접 관리하는 실행 단위다.
- 목표: 어떤 결과를 만들 것인지와 판단 기준을 가진다. 투입 시간과 결과 진척을 따로 보여준다.

주간의 기존 완료 표시는 샘플 done 상태를 표현한 것이었다. 현재 주간은 배치한 일정만 보여주고, 미이행·미룸은 명시적 상태로 보존한다. 오늘 우선순위의 체크 수와 목표 완료는 같은 값으로 계산하지 않는다.

## 연간: 방향과 중간 결과를 잡는 계획표

행은 올해 집중할 목표 1~3개, 기본 열은 1~4분기다. 한 화면에서 방향을 참고하고 선택한 분기 안에서 세 달의 세부 계획을 펼친다. 처음부터 열두 달을 한 줄에 늘어놓지 않는다. 시간표처럼 모든 시간을 채우지 않고 각 구간에 중요한 결과와 관련 할 일을 배치한다.

예시: 서비스 공개라는 목표 아래 요구사항 정리 → 시제품 → 사용자 확인 → 공개의 중간 결과를 배치한다. 월·분기 구간을 눌러 연결된 할 일을 본다. 선택적 결과 기준, 목표 기간과 현재 결과를 함께 표시한다.

분기·연간의 기본 화면은 계획표로 한다. 현재 기록 지도·달력은 되짚어보기의 보조 화면으로 이동한다. 저장된 일정을 목표로 자동 변환하지 않는다. 목표·중간 결과는 사용자가 계획표에 따로 정하고 연결된 할 일과 날짜별 일정으로 구체화한다.

## 분기: 이번 3개월의 실행 계획표

상단은 이번 분기에 만들 결과 1~3개다. 각 결과를 만드는 데 필요한 할 일을 연결한다. 본문은 3개월 열이며 목표별로 관련 할 일을 배치한다. 별도 미배치 영역에서 할 일을 원하는 달로 옮긴다.

카드의 최소 정보는 제목·작업 상태·예정 기간·목표 연결이다. 시간표의 블록을 복제한 카드가 아니라 동일한 Task ID를 가리킨다. 월간이나 오늘 시간표에 배치하면 같은 작업으로 이어진다.

## 연결 흐름

연간 목표 → 분기 중간 결과 → 할 일 → 월별 배치 → 오늘 시간 배치.

예시:

1. 연간 목표: 서비스를 공개한다.
2. 분기 목표: 첫 사용자가 일주일 동안 사용할 수 있는 버전을 만든다.
3. 할 일: 가입 화면 정리 / 모바일 시간표 점검 / 개인정보 안내 확정.
4. 달에 배치: 이번 달 가입과 시간표, 다음 달 사용자 확인.
5. 하루에 배치: 오늘 10~11시에 모바일 시간표 점검.

목표를 설정하지 않은 일반 생활·약속도 바로 시간표에 넣을 수 있다. 모든 일을 연간 목표에 연결하도록 요구하지 않는다.

## 기존 할 일 보관함 확장

- 목표 선택은 선택 사항이다.
- 예정 기간이 없으면 미배치 작업으로 남긴다.
- 날짜·달·분기로 이동할 때 같은 작업을 유지하고 중복 생성하지 않는다.
- 작업 제목·상태를 바꾸면 모든 기간의 연결된 화면에 반영한다.
- 시간표 활동 한 번을 수행한 것으로 작업 전체를 자동 완료하지 않는다.
- 미루기 이력을 도입하면 이전 예정 기간과 변경 사유를 보존한다.

## 데이터 제안

- Goal: 사용자 ID, 제목, 기간, 선택적 상위 Goal ID, 결과 기준·현재 값, 상태, 버전.
- Task: 기존 ID·제목·상태·버전을 유지하고 선택적 Goal ID와 예정 기간을 추가한다.
- Plan: 기존 taskId로 날짜별 시간 배치를 연결한다.
- Entry: 이전 실제 기록 자료는 저장·내보내기에서 보존하되, 현재 일지 UI의 집계·색·표시에는 사용하지 않는다.

목표에 연결된 작업 진행 수와 실제 결과 진척은 별도 지표다. 시간 기록으로 결과 달성을 자동 추정하지 않는다. 한 작업을 여러 화면에서 세어 전체 진척이 부풀려지지 않게 ID로 집계한다.

## 추천 첫 구현

1. 할 일에 목표와 예정 월을 선택적으로 연결한다.
2. 분기의 세 달 계획표와 미배치 영역을 만든다.
3. 그 관계를 연간 목표·기간 표에 펼친다.
4. 일간·월간에서 같은 작업을 배치하고 상태를 갱신한다.

분기·연간 목표 완료 기준과 상태 변경 조작을 먼저 확정한 뒤 완료율을 표시한다. 기존 시간 기록 지도는 이 흐름의 회고 화면으로 남긴다.

## 참고용 계획표의 기본 화면

| 목표 | 1분기 | 2분기 | 3분기 | 4분기 |
| --- | --- | --- | --- | --- |
| 서비스 공개 | 문제·대상 정리 | 시제품 | 사용자 확인 | 공개·안정화 |
| 꾸준히 운동하기 | 루틴 찾기 | 주 2회 정착 | 유지·조정 | 돌아보기 |

이 표는 제안 설명용이며 저장된 사용자 자료나 구현된 UI가 아니다. 연간의 분기 칸을 누르면 해당 분기의 세 달 계획표로 내려간다. 모바일 연간은 네 분기를 세로로 배열하고 목표별 내용을 펼쳐 본다. 분기는 기본으로 한 달을 선택하고 이전·다음 달을 바로 넘기며 세 달 전체도 볼 수 있게 한다.

항목 추가는 기존 방향대로 간단한 모달을 사용한다. 제목·예정 기간·연결할 할 일(선택)이 기본 입력이다. 목표 결과 기준과 메모는 선택적 추가 설정으로 둔다. 미배치 작업은 보관함에 남으며 특정 월에 배치해도 복제하지 않는다. 계획 참고 화면에 일간 회고·기존 일정 합계를 기본 정보로 늘어놓지 않는다.

## 일간·주간·월간에서 계획 참고하기

전체 로드맵을 항상 붙여 놓지 않는다. 기간 탭 아래 한 줄의 집중 계획을 표시한다. 예시(제안): 올해 서비스 공개 › 이번 분기 사용자 확인 › 이번 달 모바일 점검. 계획 펼치기를 누르면 결과와 연결된 할 일을 읽고 수정한다. 관련 계획이 없으면 일지에 빈 패널을 강제로 추가하지 않는다.

- 일간: 오늘 배치한 할 일과 연결된 목표 1~2개만 표시한다.
- 주간: 이번 주에 이어갈 목표·작업 2~3개를 참고하고 주간 시간표에 배치한다.
- 월간: 이번 달에 만들 결과를 참고하고 할 일을 날짜에 배치한다.
- 연간·분기: 같은 목표·작업 관계를 넓은 계획표로 편집한다.

모바일은 한 줄 요약과 펼치기를 기본으로 한다. 독립된 목표 저장·연결 기능을 구현하기 전에는 실제 UI에 가짜 목표나 저장되지 않는 입력칸을 추가하지 않는다. 접힌 기간 참고 요약과 분기 계획표 이동은 로컬에 구현했다.
