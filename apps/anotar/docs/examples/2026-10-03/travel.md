**2026년 10월 5일 월요일부터 8일 목요일까지, 난바에 3박하며 오사카·교토·나라를 둘러본다.** 마지막 날 고베는 늦은 귀국편과 충분한 체력이 확보될 때 넣는 선택 코스다. 짐을 들고 도시를 옮기기보다 한 숙소에서 머무르는 계획으로 잡았다.

> 예약 전 계획안이다. 인천 출발·성인 1명·난바 3박은 계획 가정이며 항공권과 숙소를 예약한 상태가 아니다. 아래 시간은 방문 순서를 읽기 위한 계획 시간이고 확정 운항·열차 시각이 아니다. 한국과 일본 모두 UTC+9이므로 같은 시각 기준으로 읽는다.

## 여행 개요

첫날은 입국과 적응에 여유를 두고 난바의 밤만 걷는다. 둘째 날은 교토 동쪽의 신사·사찰과 골목, 셋째 날은 나라 공원과 대불을 중심으로 움직인다. 네 도시를 모두 채우는 것보다 귀국편과 체력에 맞춰 고베를 빼는 선택을 먼저 허용한다.

| 날짜 | 중심 지역 | 꼭 남길 경험 |
| --- | --- | --- |
| 10월 5일 월요일 | 오사카 난바 | 체크인 후 도톤보리 산책과 저녁 |
| 10월 6일 화요일 | 교토 동쪽 | 후시미 이나리와 기요미즈데라 |
| 10월 7일 수요일 | 나라 | 도다이지와 공원 산책 |
| 10월 8일 목요일 | 고베 또는 난바 | 선택 코스 후 공항으로 여유 있게 이동 |

저장된 지도는 방문 순서를 보여준다. 핀은 장소 중심의 근사 위치이며 점선은 실제 도로·보행 경로가 아니다. 열차와 실제 길찾기는 지도 아래 Google Maps 링크에서 다시 확인한다.

## 먼저 확인할 것

**항공권을 먼저 확정하고 첫날과 마지막 날을 맞춘다.** 이 글은 기존 계획의 오전 출발·저녁 귀국 가정을 이어받았지만 해당 날짜의 운항·잔여 좌석·총액을 조회한 예약 견적은 아니다.

1. 10월 5일 인천 출발과 10월 8일 귀국편의 실제 공항·터미널·수하물 조건을 확인한다.
2. 난바 숙소의 3박 요금, 체크인 시간, 마지막 날 짐 보관을 확인한다.
3. 식당과 관광지의 방문일 운영·예약 필요 여부를 확인한다. 정해둔 식당은 모두 방문 후보다.
4. 집에서 출발 공항까지의 이동과 귀국 후 막차를 확인한다. 집 출발 시각은 거주지와 확정편을 기준으로 정한다.

## 1일차 · 2026-10-05

**오늘의 목적은 입국을 무리 없이 마치고 난바에 적응하는 것이다.** 인천 → 간사이공항 → 난바 숙소 → 호젠지 → 도톤보리 순서로 읽으면 된다. 간식과 관광은 체크인 이후 상황을 보고 줄인다.

난바 도착이 16시를 넘으면 와나카 간식과 호젠지를 생략한다. 짐 정리 → 저녁 식사 → 도톤보리 30분 산책만 남겨도 첫날의 목적은 달성된다.

[[ITINERARY_DAY_1]]

식당은 와나카의 다코야키, 치보의 오코노미야키를 후보로 둔다. 대기가 길면 특정 가게에 매달리지 않고 난바에서 같은 종류의 식사로 바꾼다. 메뉴 가격·예약 여부는 방문 전에 확인한다.

## 2일차 · 2026-10-06

**교토는 후시미 이나리와 기요미즈데라를 우선하고, 나머지는 걸으면서 고른다.** 난바에서 출발해 후시미 이나리 → 기요미즈데라 → 산넨자카 → 야사카·기온 → 니시키 순서로 움직인다.

오르막과 계단이 이어지는 날이다. 점심과 앉아서 쉬는 시간을 줄여 관광지를 추가하지 않는다. 기요미즈데라 도착이 늦어지거나 비가 오면 니시키 시장을 생략하고 기온에서 마무리한다.

[[ITINERARY_DAY_2]]

17:15 교토 출발은 이 계획의 귀환 목표다. 특정 열차 예약을 뜻하지 않는다. 출발 전 실제 열차를 조회하고, 난바에 돌아온 뒤 가까운 곳에서 저녁을 먹는다.

## 3일차 · 2026-10-07

**나라에서는 공원과 도다이지를 중심으로 천천히 걷는다.** 긴테쓰나라역 → 흥복사 주변 → 도다이지 → 가스가타이샤 → 나라마치 순서다. 공원에서 사진을 찍는 시간도 일정의 일부로 남겨둔다.

비가 강하거나 발이 피곤하면 가스가타이샤를 생략한다. 도다이지 관람 뒤 시내로 돌아와 점심과 카페 시간을 늘리는 것이 기본 대안이다.

[[ITINERARY_DAY_3]]

점심은 히라소의 가키노하즈시, 간식은 나카타니도의 모치를 후보로 둔다. 알레르기나 식사 제한이 있으면 메뉴를 먼저 확인한다. 사슴 주변에서는 음식과 종이류를 가방 안에 두고 안내에 따라 행동한다.

## 4일차 · 2026-10-08

**오늘은 관광보다 귀국을 우선한다.** 아래 고베 코스는 기존 계획의 19:40 출발 가정에 맞춘 선택안이다. 실제 귀국편이 18시 이전이거나 짐 보관이 어렵다면 고베를 빼고 난바에서 점심을 먹은 뒤 공항으로 간다.

고베에 가는 경우에는 메리켄 공원 → 난킨마치 → 점심만 남긴다. 13:40 고베 출발, 15:15 난카이 난바 출발, 16:50 간사이 T2 도착은 이 계획의 목표 시각이다. 항공사 수속 마감 시각을 뜻하지 않으며 발권 후 다시 계산해야 한다.

[[ITINERARY_DAY_4]]

고베 점심은 스테이크랜드를 후보로 둔다. 줄이 길면 기다리며 공항 이동 여유를 쓰지 않는다. 고베 식사를 생략하고 난바나 공항에서 먹는 대안을 바로 선택한다.

## 예약과 교통

**현재 예약 확정 건은 없다.** 예약이 완료되면 이 표에서 상태와 확인 날짜부터 갱신한다. 개인 예약번호는 공개 공유용 본문에 적지 않는다.

| 항목 | 현재 상태 | 확인할 기준 |
| --- | --- | --- |
| 왕복 항공 | 미예약 | 운항·총액·터미널·수하물 |
| 난바 숙소 3박 | 미예약 | 위치·체크인·짐 보관·취소 조건 |
| 고베 점심 | 방문 후보 | 영업·대기·예약 가능 여부 |
| 통신과 여행보험 | 준비 전 | 기기 호환·기간·보장 범위 |

간사이공항 T2를 사용하는 항공편이면 철도역까지 무료 셔틀을 거친다. 공항 공식 안내의 차량 이동은 약 7–9분이며 걷기와 대기까지 포함한 계획 시간은 별도로 둔다. [간사이공항 T2 셔틀 안내](https://www.kansai-airport.or.jp/en/access/t2/)

난카이 공항급행은 간사이공항과 난바를 약 45분에 연결하는 열차로 안내된다. 실제 출발 시각·운임은 여행일 기준으로 조회하고 라피트를 선택할 때에는 특급권 조건까지 비교한다. [난카이 열차 안내](https://www.nankai.co.jp/en_railway/access-timetable)

교토는 난바 → 요도야바시 → 게이한, 나라는 오사카난바 → 긴테쓰나라, 고베는 한신 난바선을 계획 경로로 둔다. 전광판에서 목적지와 정차역을 확인하며 지도에 제시된 노선명을 실제 승차권이나 열차 예약으로 취급하지 않는다.

## 예산

**1인 약 106만 원을 계획 상한의 출발점으로 둔다.** 아래 금액은 기존 문서의 예산 배분이며 현재 예약 가격·환율 견적이 아니다. 실제 지출은 결제 후 기록한다. 쇼핑과 택시는 이 금액 밖에 둘 수 있으므로 별도 상한을 정한다.

| 항목 | 계획 배분 | 산정 기준 |
| --- | --- | --- |
| 항공 왕복 | 450,000원 | 수하물 포함 총액 비교 전 가정 |
| 숙박 3박 | 30,000엔 | 실제 숙소·요금 미확인 |
| 식비 | 18,500엔 | 간식·고베 점심 포함 배분 |
| 공항·도시 간 교통 | 6,500엔 | 개별 운임 확인 전 여유 포함 |
| 관광·소액 활동 | 2,000엔 | 실제 입장료 재확인 |
| 통신 | 1,500엔 | 상품·기기 호환 확인 전 배분 |
| 예비비 | 6,000엔 | 지연·일정 변경 대비 |
| 보험·한국 이동 | 35,000원 | 택시 사용 시 증액 |

일본 현지 배분은 **64,500엔**이다. 계획용 환산 **1엔 = 9원**을 적용하면 580,500원, 한국 원화 항목 485,000원과 합쳐 **1,065,500원**이다. 실제 환율을 조회한 값이 아니므로 환전·결제 시 다시 계산한다.

예산을 줄여야 한다면 고베규 식사와 쇼핑부터 조절한다. 항공 수하물이나 귀국 공항 이동의 여유를 줄이는 선택은 마지막에 검토한다.

## 공유 전 확인

공유받은 사람은 날짜별 목적 → 지도와 시간표 → 그날의 축소 기준 순서로 읽으면 된다. 정해둔 장소를 모두 방문해야 하는 계획은 아니다. 예약된 것과 후보인 것을 먼저 구분하고 일정이 바뀌면 해당 날짜만 다시 확인한다.

간단한 일본어는 세 문장만 먼저 준비한다. 목적지 이름은 화면에 함께 보여주면 더 쉽게 전달할 수 있다.

| 하고 싶은 말 | 일본어 |
| --- | --- |
| 이 열차는 난바에 가나요? | この電車は難波に行きますか。 |
| 한 명입니다. | 一人です。 |
| 계산 부탁합니다. | お会計をお願いします。 |

여권번호·예약번호·입국 QR·보험 증서·개인 연락처는 공개판에서 제거한다. 공유하는 것은 방문 순서와 필요한 안내이며 개인 확인 자료는 별도로 보관한다.
