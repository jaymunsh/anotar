# 연결·설치·공유 수신 안내

anotar 개인 앱은 **온라인 전용**이다. 저장과 읽기는 모두 서버에 바로 요청하며, 예전의 기기 우선(local-first) 오프라인 작성·동기화는 제거했다.

## 연결이 필요해요

- 메모·할 일·페이지의 저장과 읽기는 서버 연결이 있어야 한다.
- 연결이 끊기면 사이드바에 **연결 끊김 · 연결 후 저장돼요**가 조용히 표시된다.
- 저장에 실패하면 입력은 지우지 않고 화면에 **저장하지 못했어요 · 다시 시도**를 보여준다. 다시 시도를 누르면 재전송한다.
- 메모 입력은 전송에 성공한 뒤에만 비운다.
- 페이지 편집기는 디바운스 자동 저장 + 저장 상태 표시(저장됨 / 저장 중… / 저장 못 함)를 쓰고, 실패 시 다시 시도할 수 있다.

## 다른 곳에서 바뀜 (409 충돌)

같은 페이지를 다른 창·기기에서 먼저 저장하면 저장이 409로 거절되고 **다른 곳에서 바뀌었어요** 안내가 뜬다. 지금 작성한 내용은 그대로 남으며 다음 중에서 고른다.

- **서버 내용 불러오기** — 최신 서버 내용을 다시 연다(내 변경은 버린다).
- **내 내용 복사** — 작성한 내용을 클립보드로 복사해 둔다.
- **내 내용으로 덮어쓰기** — 서버 최신 버전을 기준으로 내 내용을 다시 저장한다.

## 입력 손실 방지 초안

연결과 별개로, 작성 중 내용 손실을 막기 위한 localStorage 초안(빠른 입력·프롬프트·페이지 편집 초안)은 유지한다. 새로고침 후 같은 탭에서 복구할 수 있다.

## PWA 설치·앱 업데이트

- 홈 화면에 PWA로 설치할 수 있고, 서비스워커가 앱 쉘(정적 파일)만 캐시한다. API·본문·첨부는 캐시하지 않는다.
- 새 버전이 준비되면 **새 버전이 있어요 · 새로고침** 알림이 뜬다. 진행 중인 저장을 기다린 뒤 새 버전으로 다시 연다.
- 오프라인 상태로 처음 열면 앱 쉘만 보이며, 자료는 **연결이 필요해요**로 안내한다.

## OS 공유 수신

운영체제의 공유 시트에서 anotar로 텍스트·링크·파일을 보낼 수 있다(`share-target`). 받은 내용은 빠른 입력 초안으로 들어오고, 저장은 연결된 상태에서 서버로 전송한다.

## 참고 (서버 sync 계층)

서버에는 예전 동기화 계층(`server/sync/*`, `/api/sync/*`, sync 테이블·트리거)이 아직 남아 있지만 **클라이언트는 더 이상 사용하지 않는다.** 클라이언트는 `/api/captures`·`/api/tasks`·`/api/pages`와 AI·정리 REST만 쓴다.
