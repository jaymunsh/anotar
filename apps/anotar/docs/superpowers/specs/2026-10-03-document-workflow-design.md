# 자료에서 문서로: 템플릿·자료 패널·여행 읽기

사용자는 생산성/가독성/리포트 정리를 위해 제안된 자료 패널 → 목적별 템플릿 → 긴 문서 읽기 개선의 실행을 승인했다. 에이전트도 템플릿을 활용하고 여행은 더 크게 개선한다.

## 범위

1. 공통 기본 문서 템플릿(리서치, 여행, 회의, 개발 기록). 하나의 버전 있는 정의에서 편집 가능한 블록 문서와 에이전트 작성 규칙을 제공한다. 기존 사용자 템플릿 보존. 새 페이지/빈 문서에서 쉽게 선택하며 빈 페이지 시작을 유지한다. 기본 정의는 로컬 번들로도 제공하여 offline에 사용하고, 개인 읽기 API와 사용 문서로 에이전트에 노출한다. 작성 규칙은 사실/미확인/출처/예약 상태를 구분하며 예시를 실제 사실로 생성하지 않는다.
2. 페이지 옆 자료 패널: 메모·AI 결과·다른 페이지를 검색/선택하여 미리보고 명시적으로 필요한 텍스트를 현재 편집기에 추가한다. 원본 내용·AI 상태·메모 정리 상태를 변경하지 않는다. 삽입은 BlockNote 기존 local autosave를 통하고 현재 잠금/충돌/데이터 복구 상태를 존중한다. 공유에 패널이나 개인 메타데이터를 노출하지 않는다. 자동 첨부/참조 본문 재귀 복사 없이 텍스트부터 지원한다. 한 번에 단일 inspector, PC/모바일에서 기존 문서 위치와 도구 패턴 유지.
3. 여행 읽기: 날짜별 지도와 전체 시간표의 한 열 흐름 유지. 고정된 시간 열·방문 번호/활동·제목/장소·전체 안내의 정보 위계 개선. 실제 이동 경로로 오인하는 점선/확정되지 않은 예약/비용을 만들지 않는다. 기존 지도·항목·블록 ID/댓글·원문/첨부 보존. 짧고 반복 없는 일정 작성 지침을 기본 여행 템플릿/에이전트 규칙으로 제공. 기존 간사이 문서는 원본 사본을 남기고 안전한 versioned 업데이트가 가능한 경우 기존 사실만 재정리한다.

## 유지 계약

기존 branch/사용자 데이터와 미커밋 변경 보존. AI·지도 유료 요청/새 공개 링크/배포 없음. 기존 forest/paper/charcoal 디자인 및 새 글꼴·자간 유지. 모바일 320/390 조작 44px. 사용자가 읽어야 하는 일정 설명은 기본 접힘으로 숨기지 않는다. 실제 개인정보는 템플릿과 공개 API에 넣지 않는다. API는 개인 서버에만 추가한다.

## 완료 기준

실제 새 페이지에서 기본 템플릿을 선택해 editable 문서로 저장/재열기. 에이전트는 API/문서로 동일 정의·작성 규칙과 버전을 읽을 수 있다. 자료 패널에서 원본을 보면서 현재 문서에 넣고 원본이 변하지 않는다. 여행 화면은 private/public/offline의 동일 정보 순서로 읽힌다. 임시 DB UI/기능 검증과 build 및 관련 계약 테스트. 실제 데이터 변경은 사본/expectedVersion·가장 좁은 수정으로 검증한다.
