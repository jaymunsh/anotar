# 개인 기록 생산성 개선

사용자 승인 범위: 태그·가벼운 속성·범용 데이터베이스를 제외하고 문서 편집, 메모 정리, 페이지 연결, 오프라인 상태, 수정 이력 비교와 URL 북마크를 개선한다.

## 흐름
- 기존 BlockNote 조작과 저장/실행 취소를 유지한다. URL만 붙여넣을 때 일반 링크 또는 북마크를 선택한다. 본문 속 붙여넣기와 선택 텍스트 링크화는 기본 편집을 유지한다.
- 북마크 선택 시만 owner API가 공개 HTTP(S) 사이트의 메타 정보를 읽는다. DNS/리다이렉트/응답 크기/시간 제한은 기존 리서치 수집기를 재사용한다. 제목·설명·도메인과 제한된 크기의 안전한 PNG/JPEG/WebP 이미지 사본을 문서에 저장한다. 실패 시 URL 카드로 유지하며 다시 시도할 수 있다. 실행 스크립트·외부 이미지 핫링크는 저장/공유하지 않는다.
- 사용자 피드백에 따라 페이지 연결은 주소 복사·붙여넣기 방식이다. 같은 앱의 페이지 URL에 일반 링크/페이지 링크 선택을 제공하고 기존 이동 블록을 재사용한다. `/`·`@` 기존 페이지 추천과 자동 역링크 하단 UI는 제거한다. 공개 공유 발급과 개인 이동 주소를 구분하고 대상 문서를 함께 공개하지 않는다.
- 메모 정리는 원문과 기존 UUID/영수증을 보존한다. 오프라인 전송 대기 상태에서는 같은 정리를 반복 제출하지 않도록 안내한다.
- 기기 저장/서버 반영/충돌과 오프라인 본문/첨부 보관 상태를 구분한다.
- 수정 이력에서 현재 저장본과 선택한 과거 버전의 제목·아이콘·블록 변경을 비교한다. 원본 미리보기와 복원 계약은 유지한다.

## 안전 및 검증
실제 자료나 API 키를 테스트에 쓰지 않는다. 수정본·파일·UUID 재전송 계약과 공개 공유 범위를 보존한다. 단위 테스트는 북마크 파싱/주소차단/검증/공유/검색/역링크/버전 비교를 검사한다. 임시 DB 브라우저 QA로 URL 붙여넣기, 카드/링크, 페이지 연결, 비교, 오프라인 안내 및 모바일 가독성을 확인한다.
