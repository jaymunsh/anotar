# 계획 공유·페이지 도구·데이터 보존

사용자가 남은 항목 1·2·3의 구현을 승인했다. 기존 작업과 실제 data/를 보존하며 현재 워크스페이스에서 실행한다.

## 계획 공유

기존 표와 단일 지도는 유지한다. 새 `itinerary` 블록은 한국시간 기준 날짜·시작/끝 시간·일정·장소·좌표·링크·메모를 하나의 검증된 JSON 자료로 보관한다. 최대 50개 일정, 중복 없는 안정된 항목 ID, 올바른 날짜/시간/좌표/HTTP 링크만 허용한다. 일정 선택과 다중 장소 지도 선택은 같은 ID로 연결한다. 지도는 펼칠 때만 Leaflet과 OSM 타일을 불러온다. 점을 잇는 선은 방문 순서이며 실제 길찾기 경로로 표현하지 않는다. 공개 화면도 같은 자료로 일정과 지도를 표시하며 개인 API를 호출하지 않는다. HTML과 JS는 별도 파일로 제공하고 CSP를 유지한다. Markdown 내보내기에는 일정 표와 장소 링크를 포함한다. 이해하기 쉬운 새 여행 샘플을 멱등 시드로 제공한다.

## 페이지 도구

단일 페이지 복제(하위 문서 제외), 현재 문서를 재사용할 사용자 템플릿 저장·생성·삭제, 현재 페이지 직접 첨부, 선택 블록의 다른 페이지로 이동을 제공한다. 메뉴/검사 패널로 접근하고 기존 새 페이지 버튼을 유지한다. 첨부는 숨은 메모 없이 Page가 소유한다. 복제와 이동은 참조 파일 바이트를 중복 저장하지 않으며 블록 ID를 새로 만든다. 선택 부모와 자식은 중복 이동하지 않는다. 두 페이지의 기대 버전과 제출 UUID를 검증해 원자적으로 이동한다. 변경 중·미저장·충돌 상태에서는 문서를 덮어쓰지 않는다. 응답 유실 후 동일 UUID를 재사용해 중복 생성/첨부/이동/복원을 방지한다.

## 수정 이력

기존 문서의 현재 버전을 이관 시 기록하고 생성·편집·AI 반영·정리 등 모든 페이지 본문 버전을 기록한다. 페이지별 최근 100개 수정본, 제목·아이콘·본문·기록 일자를 저장한다. 목록, 읽기 전용 내용 확인, 명시적 복원을 제공한다. 복원은 최신 버전을 검증하고 새 버전으로 저장하며 페이지의 현재 계층을 유지한다. 수정본/템플릿의 첨부는 개인 화면에서 이용 가능해야 하지만 공유에는 현재 본문의 직접 첨부만 공개한다.

## 자동 백업

기존 온라인 SQLite+참조 파일 체크섬 백업을 재사용한다. 일일 한국시간·보관 개수 설정, 수동 실행, 최근 성공/실패·다음 실행 시각을 개인 백업 화면에서 확인한다. 기본은 매일 04:00, 7개 보관이며 첫 사용 시 화면에서 자동 실행을 켠다. 실시간 데이터 폴더 밖의 설정된 경로에만 기록한다. 성공 검증 후 관리 중인 백업만 정리한다. 동시 실행·재시작 중복·미완료 스냅샷을 처리한다. 복원은 기존 CLI의 새로운 빈 경로 복원만 허용한다. 공개 서버에는 백업/템플릿/이력/업로드 API를 추가하지 않는다.

## 검증

임시 DB로 마이그레이션·버전 충돌·UUID 재시도·참조·첨부/복원·자동 백업 실패/보관·공개 접근 경계를 검증한다. AI 실호출은 없다. 전체 테스트·빌드·기존 QA와 새 기능의 Chrome QA를 실행하고 PC/390/320px·밝음/어두움 화면을 확인한다. 실제 data/를 테스트에서 수정하거나 지우지 않는다.
