# 서버 이전 전 개인 워크스페이스 완성 범위

사용자 승인: 2026-09-30 서버 배포 전에 할 수 있는 작업을 계속 진행한다.

## 계약

- 실제 data와 미커밋 변경을 보존한다. 이 작업에서 commit/push/서버 배포/유료 실호출은 하지 않는다.
- 일정은 지도 이미지/방문 위치와 시간표를 함께 읽고, 모바일에서는 이미지가 먼저 나온다. 실제 도로 지도와 자체 위치 도표를 구별한다. 다음 일정 시작은 마지막 종료 시각을 제안하고 작성자가 바꿀 수 있다.
- 개인 블록 댓글은 DB에 저장하고 답글·해결·다시 열기·삭제를 지원한다. 블록 삭제 후에도 인용문과 대화를 보존한다. 공개 쓰기/작성자 정책은 제외한다.
- 오프라인 읽기 ZIP은 현재 페이지 HTML과 직접 참조 첨부만 포함한다. 원본 파일명으로 경로를 만들지 않는다. 개인 댓글/AI 내부 정보/다른 페이지는 포함하지 않는다. HTML은 기존 공개 렌더러의 이스케이프를 사용한다. 외부 지도 링크는 온라인에서 연다.
- AI 결과의 체크리스트를 작성자가 선택·수정한 뒤 할 일로 채택한다. UUID 재전송을 중복 생성하지 않는다.
- OCR은 명시 요청 때만 신뢰된 별도 HTTP 실행기로 이미지 전송하며 원본 바이트/본문을 덮지 않는다. 로컬 모델 설치와 실제 제공자 연결은 필요하지 않다.
- 검색은 기존 SQLite 파생 인덱스에 Task/완료 AI 결과/OCR 텍스트를 추가하고 개인 API에만 노출한다. 프롬프트 이전 수정본은 새 수정본으로 복원한다.
- Docker 준비·헬스체크·복원 절차와 로컬 측정을 진행한다. 실제 N100·원격 백업·도메인/Tailscale/Tunnel은 서버 이전 시 검증한다.
