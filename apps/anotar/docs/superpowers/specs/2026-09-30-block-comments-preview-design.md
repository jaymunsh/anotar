# 블록 댓글 미리보기 설계

## 목적과 범위

개인 페이지에서 향후 읽기 전용 공유 화면의 블록 댓글 경험을 직접 시험한다. 현재 개인 API에는 인증과 공개 권한 경계가 없으므로 외부 공개와 댓글 저장은 이번 화면에 포함하지 않는다. 사용자에게는 항상 `댓글 미리보기 · 저장되지 않음`을 표시한다.

## 화면 흐름

1. 페이지 상단의 `댓글 미리보기`를 누르면 제목과 본문 편집이 잠긴다. 저장 중인 변경이 있으면 저장 완료 또는 실패를 확인한 뒤 열 수 있다.
2. 안내줄은 본문을 읽고 블록을 선택하라고 안내한다. 블록을 누르거나 키보드로 안내줄의 블록 목록에서 고르면 해당 블록을 강조하고 댓글 패널을 연다. 다른 블록을 골라 대상을 바꿀 수 있다.
3. 패널은 선택한 블록의 짧은 인용과 그 블록의 스레드를 보여준다. 빈 블록에도 댓글을 달 수 있다. 첫 댓글, 답글, 해결, 다시 열기를 시험한다. 댓글 내용은 빈 문자열로 등록되지 않는다.
4. 이미 댓글이 달린 블록은 작은 표시를 가진다. 해결된 댓글은 진행 중 댓글과 구분된다.
5. 데스크톱은 문서 옆 패널, 모바일은 닫을 수 있는 하단 패널로 보여준다. Esc로 패널을 닫을 수 있다. 미리보기를 종료하면 편집 가능 상태로 돌아간다.
6. 임시 댓글은 브라우저 메모리에만 있고 미리보기를 닫거나 페이지를 새로고침하면 사라진다. 페이지 API 호출이나 공유 URL을 만들지 않는다.

## 향후 저장/공유 경계

- 댓글 연결 키는 `pageId + blockId`로 설계한다. 블록 편집·삭제로 연결 대상이 없어졌을 때 보여줄 상태는 실제 저장 기능을 만들 때 결정한다.
- 개인 문서와 공개 읽기 서비스는 별도 접근 경계를 둔다. 공개 페이지와 첨부는 명시적 허용 목록만 제공한다.
- 방문자의 작성 허용 기준, 신원, 스팸 방지, 알림, 보존/삭제 정책은 아직 미정이다. 이 결정을 내리기 전에는 실제 공개 댓글 POST API를 만들지 않는다.

## 검증

- 실제 브라우저에서 블록 선택→댓글→답글→해결→다시 열기→종료→새로고침을 확인한다.
- 새로고침 후 댓글이 없고 원본 페이지 문서가 바뀌지 않아야 한다.
- 1440px, 390px, 320px과 밝음/어두움에서 내용이 겹치거나 가로 스크롤되지 않아야 한다.
