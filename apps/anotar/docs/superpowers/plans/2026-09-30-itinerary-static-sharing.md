# 일정 활동 유형과 이미지 공유 구현 계획

**목표:** 기존 일정·장소를 보존하면서 OSM 의존성을 제거하고 활동 유형·소요시간·겹침 안내와 이미지 기반 공유를 제공한다.

**승인된 방향:** 개인 화면은 필요할 때 Google 지도, 공유 화면은 저장 이미지와 외부 장소 링크. 관광·이동·식사·휴식·숙박·기타는 선택 사항이다. 전체 오프라인 앱·경로 계산은 이번 범위에 포함하지 않는다.

## 구현

- [x] 일정 검증에 선택적 `category`를 추가한다. 소요시간·겹침·이동을 제외한 방문 번호는 공통 함수로 계산한다. 이전 version 1 문서를 그대로 읽는다.
- [x] 일정/장소 블록의 선택적 `assetId`로 기존 이미지 첨부를 선택한다. 새 이미지 참조의 MIME·접근 권한, 공유 범위, 복제·템플릿·수정 이력의 참조 보존을 함께 처리한다.
- [x] Google 지도만 개인 화면에서 지연 로딩한다. 기존 단일 장소 블록은 좌표·이름과 Google 링크로 유지한다. Leaflet 패키지·OSM iframe/타일/공개 SDK 경로를 제거한다.
- [x] 공유에는 일정 이미지와 링크를 출력한다. 등록 이미지가 없으면 자체 생성한 방문 위치·순서 SVG를 사용하고 실제 도로 지도와 구분한다. Google 자동 캡처는 구현하지 않는다.
- [x] 활동 유형·소요시간·겹침·이미지 교체·저장/재조회·공유 격리·이미지 실패를 임시 DB와 브라우저에서 검증한다. 1440px/390px/320px 및 밝음/어두움 화면을 확인한다.
- [x] 새 샘플을 추가하고 현재 규격·공유 문서·에이전트 지침을 갱신한다. 기존 샘플을 덮지 않는다.

## 주요 검증

선택하지 않은 유형, 좌표 없는 방문, 좌표가 있는 이동, 같은 시간/맞닿는 시간/서로 다른 날짜, 없는 이미지·파일 MIME, 참조 제거 뒤 수정 이력, 휴지통 원본, 공유 토큰 폐기, 외부 지도 요청이 없는 공개 화면을 확인한다.
