# 개인 작업 공간 완성 순서

이 문서는 기존 [순차 개발 계획](../../../PLAN.md)의 남은 부분을 현재 코드 기준으로 쪼갠 작업 순서다. 혼자 쓰는 앱이므로 협업 편집·공개 가입보다 자료 보존, 개인 접근, 수집 속도, 읽기 전용 공유를 먼저 검증한다. 각 항목은 독립적인 설계·구현·복원/브라우저 QA로 끝낸다. 후속 구현 계획에는 파일·API·마이그레이션과 실패 시 복구 절차를 구체화한다.

| 순서 | 결과물 | 현재 상태 | 완료 기준 |
| --- | --- | --- | --- |
| 1. 블록 댓글 화면 | 페이지에서 블록별 댓글·답글·해결 UX 시험 | **개인 댓글 저장 구현**. 블록 옆 표시·스레드 목록·답글·해결·삭제·위치 없는 블록 인용 유지 | 320/390/1440px 밝음·어두움, 원본 Page 불변, 새로고침 후 유지 |
| 2. 백업과 되돌리기 | SQLite와 첨부를 함께 묶는 스냅샷, 복원 도구, 일반 Page 수정 이력 | **로컬 구현·검증 완료**. 수동 백업·검증·새 경로 복원 CLI, 최신 100개 페이지 수정 이력·복원, 기본 꺼짐 한국시간 일일 백업과 검증 후 보관 정리 | 기존 로컬 검증은 [보존 계획](2026-09-30-plan-page-preservation.md) 참조. 원격 보관과 실제 N100에서의 복원 점검은 남음 |
| 3. 개인 접근 경계 | N100의 개인 앱을 Tailnet 안에 두고 Compose 이관 문서 작성 | Compose의 개인·공유 서버는 별도 네트워크와 로컬 루프백 포트로 분리됨. 개인 앱 자체 인증 없음 | Tailscale Serve만 개인 API에 도달. 외부 네트워크에서 개인 API·원본 파일 직접 접근 거부. 설정·백업으로 새 호스트 복원 |
| 4. 읽기 전용 공유 | 공개 서비스 분리, 페이지·첨부 허용 목록, 링크 폐기·만료 | **로컬 구현**. 개인 발급 UI·현재 첨부 범위·별도 읽기 전용 서버·Compose 분리·토큰 만료/폐기/재발급. 실제 외부 도메인·Tailscale 인증은 미검증 | 공유 링크에서 지정 페이지/본문 첨부만 조회. 다른 ID와 개인 API·검색·AI·업로드 접근 거부. 폐기/만료 즉시 차단. 내 화면에서 공유 범위 확인 |
| 5. 댓글 저장과 알림 | 공유 페이지 블록 스레드의 저장·해결·관리 | **이름 기반 공유 댓글·받은함 구현** | 링크별 허용 기본 꺼짐, 이름 댓글·답글·개인 관리·미확인/미해결 분리·직접 이동. 외부 알림/신고·방문자 본인 인증은 현재 제공하지 않음 |
| 6. 수집 확장 | 모바일 공유 대상/붙여넣기, URL 본문 보관, 이미지 OCR | 개인 설치/공유 진입 `/capture`와 검토 후 초안 가져오기를 제공. Android 등 지원 브라우저의 공유 대상 계약을 구현했고 실제 OS 메뉴는 기기에서 확인. iOS Safari는 복붙·직접 첨부. URL 리서치는 AI 요청 시 제한적으로 수집. 일반 URL 아카이브 없음. OCR 큐/게이트웨이·상태·결과·이력 UI 구현, 실제 실행기 미연결 | 휴대폰 공유 메뉴에서 입력 초안 확인 후 저장. URL 원본+수집 시각+본문 출처를 보관하고 실패해도 링크 원본 유지. OCR 제안은 원본과 분리해 검토 후 반영 |
| 7. 주의 화면과 작업 | 할 일 기한 알림·반복, 실패·대기 항목의 한곳 보기 | 할 일 기한·상태, AI 현황, 공유 댓글 받은함과 일정 준비 할 일 연결은 있음. 기한 알림·반복은 없음 | 알림 중복/시간대/오프라인 실패 재시도 확인. 한국시간 기준 다음 실행과 완료 후 반복 생성 검증. 홈에서 급한 항목을 바로 처리 |
| 8. 페이지 보기 확장 | 가벼운 속성·필터·보기 | 블록 페이지·사이드바 계층·목차·넓게 보기·작은 글씨·복제·사용자 템플릿·선택 블록 이동은 구현. 속성 기반 목록/필터는 없음 | 실제 사용하는 속성 2~3개부터 추가. 목록/필터가 1천 페이지에서도 빠르고 기존 블록 JSON·Markdown 복사가 유지됨 |

## 서버 이전 전 로컬 개발 우선순위

2026-09-30 배포 전 완성 작업은 [실행 계획](2026-09-30-predeployment.md)과 [검증 기록](../../../.omo/evidence/predeployment/REPORT.md)을 따른다.

1. **일정:** PC 지도/시간표 2열, 모바일 이미지 우선, 시간·활동 강조, 접는 편집 항목, 직전 종료시간 제안을 구현했다. 실제 도로 지도 자동 이미지 생성은 포함하지 않는다.
2. **오프라인:** 현재 페이지·직접 첨부 ZIP과 네트워크 없는 읽기를 구현했다. 전체 앱의 오프라인 편집/동기화는 별도다.
3. **댓글:** 개인 스레드·답글·해결·삭제를 영속화했다. 이름 기반 공유 댓글·답글·개인 관리와 받은함을 구현했다. 외부 알림은 없다.
4. **수집·AI:** 명시 OCR 큐/게이트웨이와 결과 확인, 선택 AI 결과의 할 일 등록을 구현했다. 실제 OCR 제공자 설정·품질 검증은 남는다.
5. **검색·관리:** Task·완료 AI 결과·OCR FTS 검색과 정확한 결과 이동, 프롬프트 과거 수정본을 초안으로 불러오는 UI를 구현했다.
6. **이전 준비:** Docker 헬스체크·Linux/amd64 설정과 운영 백업 CLI·새 경로 복원·제한된 공유 댓글 socket 검증 명령, 실제 이전 실행 안내를 제공한다. 실제 N100 성능·Tailscale/Tunnel·원격 백업은 운영 환경에서 검증한다.

## 공통 배포 원칙

- 개발은 이 로컬 저장소·임시 데이터 디렉터리에서 검증하고, 미니PC로는 Docker 이미지·Compose 설정·백업 데이터로 옮긴다. 실제 `data/`와 예시 자료를 QA로 덮어쓰지 않는다.
- 새 기능은 N100/16GB/512GB에서 별도 성능·자원 측정을 한다. Apple 개발 머신 수치를 운영 장비 결과로 주장하지 않는다.
- 외부 AI 실행은 사용자가 누른 작업만 보낸다. 설치형 Devin/선택적 API 경로와 원본 저장 동선은 분리한다.
- 공유 서비스는 개인 API를 프록시하지 않는다. 댓글 쓰기만 예외로 열려야 하는 경우에도 확정된 이름 정책·Origin·속도 제한을 유지한 별도 댓글 전용 엔드포인트만 제공한다.

## 이번 이전 준비 범위

[2026-09-30 이전 준비 계획](2026-09-30-migration-ready.md)은 댓글 받은함·모바일 수집·일정 연결·실제 Docker/복원을 다룬다. 일반 URL 본문 아카이브, 반복/기한 외부 알림, 속성 DB 보기, 전체 앱 오프라인 편집은 다음 개선 범위이며 서버 이전의 필수 조건으로 추가하지 않는다. 실제 서버 접근·DNS/TLS·재부팅·외부 백업 검증은 [배포 안내](../../DEPLOYMENT.md)의 대상 장비 체크를 따른다.
