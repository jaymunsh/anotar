# 이름 기반 공유 댓글 구현

> 승인된 이름/패널 방향과 사용자의 ‘아무튼 진행해봐’에 따라 이 작업공간에서 연속 진행한다. 커밋/배포는 수행하지 않는다.

설계: `docs/superpowers/specs/2026-09-30-shared-comments-design.md`

1. 백엔드: 공유 정책 이관, 별도 shared comment 저장소, 개인 관리 API, Unix socket broker, 공개 댓글 API와 방어적 입력 검증. 기존 DB 읽기 전용 경계/백업 유지. 대상 단위 및 HTTP 테스트.
2. 공개 화면: 댓글 블록 ID/작은 정적 JS/CSS, 이름 기억·인용·패널·답글·초안·모바일·두 테마. 숨은 블록 ID 노출 금지. 렌더러/브라우저 확인.
3. 개인 화면: 공유 옵션과 정책 수정, 개인/공유 대화 선택, 실제 이름/작성자·가벼운 인용·조밀한 패널. 개인 댓글과 초안 보존. 타입 빌드와 기존 댓글 QA.
4. 통합: Compose socket volume·설정·도메인 안내, 구현/디자인/작업 지침 갱신. 전체 테스트·빌드·scoped 브라우저 QA·공개 경계 확인 후 예시에서 보여준다.

진행 기록: `.omo/evidence/shared-comments/REPORT.md`. 각 작업의 파일 소유권은 작업 메시지로 지정한다. 다른 작업자의 변경은 되돌리지 않는다.
