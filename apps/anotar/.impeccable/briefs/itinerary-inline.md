# 일정 직접 편집

목적: 여행 시간표를 읽다가 시간·제목·장소·설명을 노션 속성처럼 그 자리에서 고친다. 전체 일정 폼과 항목 펼침을 반복하지 않는다.

- 기존 시간표/지도/목차의 시각 규칙을 유지한다.
- 한 속성만 입력으로 바꾸고 Enter/blur로 검증 후 Page 자동 저장, Escape는 해당 변경 취소.
- 설명은 여러 줄, Ctrl/Cmd+Enter 확정. 한글 조합 중 Enter는 저장하지 않는다.
- 날짜/링크/좌표/순서/삭제는 작은 행 메뉴. 좌표는 두 값 검증 후 적용하며 취소는 저장된 좌표로 복원.
- 지도는 계속 보이고 외부 지도 API를 자동 호출하지 않는다.
- 초안 키·항목 ID·파일 메타데이터·준비 연결·Page 버전 충돌을 보존한다.
- 기존 초안은 검토 후 명시 반영. 실패 재시도로 입력을 잃지 않는다.
- 모바일 입력 16px/44px, 읽기 설명 13px. 테마는 warm paper/forest를 유지한다.
