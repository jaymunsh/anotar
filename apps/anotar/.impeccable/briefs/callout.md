# 문서 콜아웃

- Mode: Read / Operate. 여행 주의·짧은 안내·결정을 문서 흐름 안에서 강조한다.
- 기존 종이 면과 숲색·공통 서체를 유지하며, 기본은 투명 배경·얇은 1px 테두리다. 배경색 9종과 테두리 유무는 사용자 선택이다.
- 슬래시 메뉴로 추가하고 박스 본문을 바로 편집한다. 왼쪽 아이콘에서 아이콘·색·테두리만 고르는 작은 메뉴를 연다. 별도 본문 편집 모달은 없다.
- 공유·오프라인 사본은 같은 박스·아이콘과 children을 출력한다. 개인 페이지 링크 하위 자료와 개인 댓글의 공개 제외 계약을 유지한다.
- 터치 메뉴는 최소 44px, 작은 화면에서 viewport 안에 놓이고 Escape와 바깥 클릭으로 닫힌다. 밝은 화면과 어두운 화면의 대비를 유지한다.
- 색·아이콘은 유한한 공통 목록으로 검증하고 inline 본문·하위 블록·ID를 기존 저장/동기화/이력에 보존한다. Markdown은 인용문 텍스트로 내보낸다.
- 검증: `.omo/evidence/architecture-callout/verification.json`, PC/모바일·공유/오프라인 스크린샷. 실제 휴대폰 IME/PWA 설치와 서버 배포 검증으로 확대하지 않는다.
