# AI 요청 실행

## OpenCode 모델 관리 확장 · 2026-10-05

설정의 기존 AI 영역에 기본 OpenCode 모델과 접을 수 있는 모델 목록을 둔다. ID·표시 이름·가격 안내·사용 여부를 직접 편집하며 검색·필터·추가·삭제·공식 목록 갱신을 제공한다. 서버 구성 여부와 실제 모델 응답 확인은 구분한다. 갱신은 로컬 이름·사용 여부·가격을 보존하고 새 모델을 비활성으로 추가하며, 저장 전 초안으로 남는다. 요청의 기존 실행기 선택기에 사용 중인 OpenCode 모델을 넣고 제출 시 해당 모델을 고정한다. Hive/Devin 흐름과 기존 paper/forest·charcoal/sage 토큰·설정 모달을 유지한다. 좁은 화면에서는 행을 세로로 배치하고 모델 목록을 내부 스크롤한다. 별도 시각 체계나 전역 토큰 변경은 없다.

Mode: Operate. 기존 Capture 상세·AI 요청 목록과 Page의 작은 도구 줄을 확장한다. paper/forest, charcoal/sage, Noto Sans KR/DM Sans, NEW 배치와 카드 높이를 유지한다.

## 흐름

작성란 체크·템플릿은 그대로, 저장 직후 원문 보관과 백그라운드 실행을 안내한다. 목록의 기존 두 번째 줄에 준비/대기/처리/결과/연결 필요/실패를 짧게 표시한다. 상세에는 결과와 상태를 먼저, **요청 당시 입력·프롬프트**는 펼침으로 둔다. 이전 기록은 필요할 때만 펼친다. **현재 메모로 다시 요청**은 최신 저장 원문과 처음 보관한 템플릿·추가 지시를, **실패한 요청 그대로 재시도**는 실패한 작업의 사본을 사용한다. 결과는 Markdown 텍스트로 안전하게 확인·복사한다. 실행기 Devin CLI와 앱이 명시적으로 전달한 모델(기본 `swe-2-high`)은 작업 기록에 따라 구분해 표시하며 모델 설정·사용량 계약을 바꾸거나 비용을 추정하지 않는다.

선택한 완료 결과의 **결과를 페이지로 정리**는 기존 인라인 가져오기 화면을 확장한다. 기본은 새 페이지이며 기존 페이지·선택한 상위의 새 하위 페이지를 고를 수 있다. 새 제목은 맨 앞 H1을 제안하고 같은 제목의 본문 중복을 제거한다. 결과·별도 자료 출처를 함께 담고 원문·첨부는 추가 선택한다. 원본은 정리 완료로 보관하며 본문에는 메모 카드·태그를 자동으로 넣지 않는다. 원본 출처·선택한 당시 AI 요청/결과는 개인 **페이지 정보 → 원본 메모**에 지연 표시한다. 기존 원본 블록도 본문·Markdown에서 숨기되 저장 JSON은 보존한다. **입력함 / 정리 완료**와 **입력함으로 되돌리기**로 원본을 다시 찾는다. 일반 목록·개수·검색의 정리 전 범위를 유지한다.

페이지 도구의 **페이지 AI 요청**을 누르면 인라인 **페이지 AI**를 연다. **페이지 전체**가 기본이고 편집기에서 글을 선택한 뒤 **선택한 블록**을 요청할 수 있다. 저장된 제목·문서·버전·입력·선택·프롬프트 사본을 고정하며 미저장·오류·충돌·초안 복구 상태에서는 먼저 저장 안내를 보인다. 참조 대상 본문·파일 바이트는 자동으로 보내지 않는다. 실행 중에는 편집을 이어 간다. 결과를 **AI 제안**으로 보여주고 **본문 아래 추가 / 선택한 블록 교체 / 새 하위 페이지**로 명시 반영한다. 교체는 선택한 저장 블록과 요청 버전이 유지된 경우만 열며 **요청 후 문서가 수정됨**에서는 추가·하위 페이지·재요청을 안내한다.

결과 제출 시에만 Markdown parser를 불러와 실제 블록 JSON으로 저장한다. 전체 Page를 Markdown으로 왕복 교체하지 않고 다른 블록·첨부·목차·페이지 링크를 보존한다. 추가·교체의 **AI 반영 되돌리기**는 반영 직전 저장 문서·제목을 복원하지만 이후 편집은 덮지 않는다. 새 하위 페이지는 휴지통 이동으로 되돌린다. Page 편집은 원본 Capture·요청 사본·AI 작업 결과를 바꾸지 않는다. 일반 변경 이력 복원·Task 채택·공개 공유는 후속 범위다.

## 상태

가벼운 로딩, 대기·처리, 완료, 실패·명시적 재요청, 미연결, 이전 내용 기준, 첨부 제외를 구분한다. 페이지 담기는 변환·저장 중, 제출 확인 대기, 조회/변환/저장 실패를 기존 안내로 표현한다. pending 동안 결과·대상·선택·변환 문서·UUID를 고정하고 **같은 요청 다시 확인**을 제공한다. 응답 유실·같은 탭 새로고침 뒤에도 최초 제출 사본을 재사용하며 새 UUID의 명시적 가져오기는 새 블록 ID를 만든다. Page 요청·반영·되돌리기도 페이지별 최초 UUID·본문을 보존해 이동·새로고침 뒤 확인한다. 대기 중 새 AI 제출은 막고 반영/되돌리기 확인 중 또는 손상된 복구는 Page 편집도 잠근다. 확인된 실패에는 **확인된 실패 닫기**, 불명확한 실패에는 같은 요청 확인을 제공한다. 성공 후 최신 Page를 조회해 늦은 영수증이 새 편집을 덮지 않는다. 상태를 색 하나로만 구별하지 않는다. 테스트 실행기의 응답은 작은 테스트 표시를 한다. 새로운 창이나 모달은 추가하지 않는다. 상세·패널이 닫히거나 탭이 hidden이면 AI 상태 요청을 중단한다.

## 구성과 확인

본문 대비는 theme ink, 보조 설명은 theme muted; 오류는 기존 semantic tokens. 원문과 결과는 줄 간격 1.7, 작은 도구 줄은 44px 조작 영역. 긴 URL·Markdown·한국어·재요청 메시지는 320/390/1327px에서 넘치지 않도록 한다. 기존 페이지 편집기와 Mermaid를 기본 입력 번들에 끌어오지 않는다. 여섯 viewport/theme captures 한 묶음으로 확인하고 확인 라운드는 최대 둘, detector 한 번, 마지막에는 fresh finish review와 scoped documentation.
