## Platform

## 목적과 사용자
혼자 하루를 관리하는 사람이 시간표에 일정을 배치하고 하루를 돌아본다. 별도의 실제 시간 기록을 작성하는 흐름은 현재 일지 UI에 제공하지 않는다. 사용자는 시간 낭비 여부를 돌아보고 싶어 한다. 로그인 후 첫 화면은 오늘 시간표다.

## 확인된 요구
기존 개인 서비스는 personal.leneu.store, 새 서비스와 소개는 leneu.store. 기존 anotar 로고·느낌을 그대로 사용한다. 오늘·할 일·기록으로 확장하며 일정 완료와 장기 할 일 완료를 구분한다. 소개·로그인/가입·개인정보처리방침·이용약관·운영자/문의 안내를 제공한다.

## 기반과 범위
이전 설계의 React/TypeScript·Node24·SQLite를 사용하고 별도 서비스·DB로 격리한다. 기본 로그인/비밀번호는 확정. 아이디+비밀번호 방식이 확정됐으며 가입 때 복구코드를 제공한다. 결제·AI·광고·분석 SDK·팀 공유·첨부는 이번 첫 버전에 없다.

## 확인된 운영 사실
운영자는 문성혁, 개인 운영. 공개 연락처는 support@leneu.store. 전달 대상 Gmail은 운영 설정에서만 다룬다. Oracle Osaka/ap-osaka-1에서 새 서비스를 분리 배포했고 2026-10-12 정책을 게시하고 회원가입을 열었다. 제공자 설명은 실제 기술 구성과 공개 개인정보 안내에 근거하며 법적 적합성 인증으로 주장하지 않는다. 기본 개발/설치 환경은 회원가입을 끈다.

## 브랜드와 접근성
승인된 anotar 아이콘과 기존 녹색·아이보리·타이포그래피를 이어받는다. 이미지로 인터페이스를 대신하지 않는다. 입력과 필수 조작은 키보드·모바일에서 사용 가능해야 한다.

2026-10-12 사용자 지정 참고는 Notion의 한국어/영어 공식 소개 사이트다. 소개는 넓은 흰 여백, 중앙의 큰 제목, 짧은 설명과 제품 화면으로 구성한다. 앱 본문은 작은 기본 글자 크기를 유지한다. 한국어/영어 전환은 소개·가입·플래너·설정·정책에 적용하고, 언어는 현재 브라우저에 저장한다. 사용자 일정·메모 원문과 편집 초안은 언어 변경으로 번역하거나 초기화하지 않는다.

## 일지 기준 (2026-10-12 사용자 확인)
핵심 화면은 기존 personal /journal의 24시간 × 10분 시간표다. 왼쪽은 오늘 꼭 할 일 → 머릿속 생각 → 아이디어 → 하루 돌아보기. 일간·주간·월간·미이행 되짚어보기를 제공한다. 소개 체험과 로그인 후 화면은 같은 Journal 컴포넌트를 사용한다. 기존 계정의 계획·실제 기록·메모는 보존하고 우선순위를 선택 필드로 추가한다. 개인 서비스 자료를 신규 계정에 자동 복사하지 않는다. 이번 변경은 로컬 확인 후 배포한다.

2026-10-13 로컬 확장: 연간 목표×네 분기 로드맵과 세 달 분기 실행 계획을 별도 planning 자료로 저장한다. 목표/세부 계획의 기간·메모·기존 할 일 연결, 일간·주간·월간의 접힌 계획 참고 요약을 제공한다. 같은 Task ID로 일간 배치하며 자동 완료하지 않는다. 저장한 보기·날짜를 주소에 반영한다. 기존 분기·연간 기록 달력은 현재 기본 UI에서 쓰지 않으며 기존 일지 데이터는 보존한다. 이동 이력·성과 수치·드래그는 후속 범위다.

2026-10-13 내비게이션 정리(로컬): 상단 일정·할 일·계획·되짚어보기. 일정에는 일간/주간/월간, 계획에는 분기/연간을 배치한다. 넓은 화면은 날짜 제목과 날짜 이동 사이에 기간 선택을 중앙 정렬하고 좁은 화면은 별도 줄로 내려보낸다. 기존 보기 주소를 지원하며 선택 날짜·기존 데이터·초안 보호를 유지한다.
