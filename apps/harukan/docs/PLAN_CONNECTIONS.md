# 계획 연결의 후속 방향

2026-10-13 설계 후보. 아래 연결 기능은 아직 구현하지 않았다.

## 현재

목표와 세부 계획에는 사용자별 고유 ID, 기간, 메모, 저장 버전이 있다. 세부 계획의 `parentId`로 목표를 연결한다. 월 제목은 해당 월간 일정으로 이동하고, 일간·주간·월간에서 겹치는 기간 계획을 접어서 참고할 수 있다. 독립 할 일은 종료했다.

## 다음 연결 후보

1. **계획 → 실제 일정 배치**: 세부 계획에서 날짜·시간을 정하면 기존 활동 작성 모달을 연다. 사용자가 저장할 때 일정에 해당 계획 ID를 연결한다. 제목 복사만으로 관계를 추정하지 않는다. 같은 계획을 여러 날짜에 나누어 배치할 수 있다.
2. **계획 → 관련 일지·회고**: 날짜별 생각/회고에서 관련 계획을 선택한다. 계획을 열면 연결된 날짜의 일지로 바로 이동한다. 같은 메모를 양쪽에 복사하지 않는다.
3. **기간별 확인**: 배치한 시간, 직접 표시한 미이행·다시 계획한 활동을 계획별로 볼 수 있다. 시간이 지났다는 이유로 목표 완료나 미이행을 자동 판정하지 않는다.

첫 연결은 활동의 선택적 계획 ID가 가장 단순하다. 사용자 소유권·삭제 정책·버전 충돌을 함께 검증해야 한다. 계획 삭제 시 연결된 일정/메모 본문을 삭제하지 않고 연결만 해제한다. 계획 이동 이력이나 성과율은 실제 사용 필요가 확인된 뒤 범위를 정한다.

별도 할 일 목록이나 루틴 기능을 이 연결의 선행 조건으로 다시 만들지 않는다. 인터페이스에 작동하지 않는 ‘연결 예정’ 버튼도 추가하지 않는다.
