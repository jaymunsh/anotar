# harukan 정책 정리

작성: 2026-10-18. 화면에 게시하는 원문은 `src/legal.tsx`(개인정보처리방침 `/privacy`, 이용약관 `/terms`, 운영자 `/about`, 문의 `/contact`)이고, 이 문서는 그 내용을 한곳에 모은 운영용 요약이다. **정책을 바꾸면 `legal.tsx`, 이 문서, README '이용 한도' 표를 같이 고친다.** 사실관계(서버 위치·제공자·운영 반영)는 [PUBLIC_INFORMATION.md](PUBLIC_INFORMATION.md).

## 개인정보처리방침

### 처리하는 정보

| 정보 | 목적 | 보유 기간 |
|---|---|---|
| 이메일, 닉네임, 이메일 확인 시각, 비밀번호 해시, 가입 시각, 약관 확인 버전 | 회원 식별·로그인·화면 표시·비밀번호 재설정 | 회원 탈퇴까지 |
| 일정·실제 활동·할 일·메모·날짜·시간대·변경 버전 (목표·세부 계획·루틴·하루 틀 포함) | 플래너 저장과 조회 | 삭제 또는 탈퇴까지 |
| 이메일 확인·재설정 링크의 해시와 보낼 주소 | 주소 확인·비밀번호 재설정 | 사용 즉시 삭제, 미사용 시 확인 3일·재설정 30분 뒤 만료, 이후 1시간 안에 정리 |
| 로그인 세션 식별자와 요청 확인 값(CSRF) | 로그인 유지·요청 검증 | 로그아웃하거나 마지막 이용 후 30일 |
| IP·이메일에서 만든 시도 제한용 해시 | 로그인·가입·재설정 남용 방지 | 최대 24시간, 이후 1시간 안에 정리 |
| 탈퇴 계정의 무작위 ID와 탈퇴 시각 | 백업 복구 때 탈퇴 계정 되살림 방지 | 8일 |
| 문의 메일과 내용 | 문의 처리 | 처리 완료 후 1년 |

- 가입에는 이메일·닉네임만 받는다. 전화번호·주소·실명은 받지 않는다. 닉네임은 본인 화면에만 보인다.
- 비밀번호는 원문으로 저장하지 않는다. 앱은 요청 본문·비밀번호를 로그로 남기지 않는다.
- 광고·행동 분석 SDK·외부 AI 실행 없음. 기록을 다른 사람에게 공개하는 기능 없음. 기록을 광고나 모델 학습용으로 제공하지 않음.

### 파기와 백업
- 탈퇴하면 계정·세션·메일 링크·일정·할 일·메모·목표와 계획을 운영 DB에서 바로 삭제(외래 키 CASCADE).
- 백업은 같은 서버에 매일(04:30 KST) 만들고 7일 지난 사본은 다음 실행 때 제거. 탈퇴 전 백업에 남은 자료도 이 주기로 사라진다.
- 백업을 복구하면 탈퇴 기록을 적용하고 모든 로그인 세션을 폐기한다.
- 이용자가 내보낸 JSON 사본은 이용자가 관리한다.

### 처리 위탁과 국외 이전

| 제공자 · 위치 | 항목 · 목적 |
|---|---|
| Oracle · 일본 오사카(ap-osaka-1) | 계정 해시·플래너 자료·백업의 서버 보관 |
| Cloudflare · 미국 및 글로벌 네트워크 | 접속 IP·요청의 보안 연결과 전달, 문의 메일 라우팅 |
| Resend · 미국(발송 지역 도쿄) | 받는 주소와 메일 내용(확인·재설정 링크) 발송 |
| Google(Gmail) · 미국 및 글로벌 | 문의 메일 수신·보관 |

국외 처리를 원하지 않으면 가입 전 중단하거나, 내보낸 뒤 탈퇴할 수 있다.

### 기기 저장과 쿠키
- 필수 세션 쿠키 하나(운영 `__Host-anotar-planner`, HttpOnly·Secure·SameSite=Lax).
- 브라우저 저장: 글자 크기·언어·화면 설정, 저장 실패 시 초안(계정·날짜별, 같은 계정으로 로그인해야 복구).

### 권리와 보호
- 설정에서 내보내기와 탈퇴. 열람·정정·삭제·처리정지는 문의 메일로, 최소한의 본인 확인 후 처리.
- 보호 조치: 비밀번호 해시, HTTPS, 계정별 접근 범위, 세션 쿠키, Origin·CSRF 검증, 시도 제한.
- 만 14세 미만은 가입할 수 없다.

## 이용약관

- **서비스와 가입**: 목표와 세부 계획, 하루 시간표·할 일·메모, 이를 모은 회고의 저장과 조회. 만 14세 이상이 이메일·닉네임·비밀번호로 가입. 타인의 이메일·계정·자료를 무단으로 쓰거나 운영을 방해하면 안 된다.
- **계정과 복구**: 이메일로만 로그인하고(아이디 없음), 비밀번호는 그 이메일로 받은 링크로 재설정. 주소를 잃으면 재설정할 수 없으니 설정에서 최신으로 유지. 운영자는 비밀번호 원문을 모른다.
- **작성한 내용**: 권리는 이용자에게 있다. 운영자는 제공·보관·백업·문제 해결에 필요한 범위에서만 처리한다.
- **이용 한도**: 아래 표. 보통 이용에선 닿지 않고, 바꿀 때는 먼저 안내한다.
- **운영과 변경**: 점검·장애로 잠시 멈출 수 있다. 주요 변경·종료는 미리 안내하고 내보내기 방법을 준다. 유료화하면 조건·요금을 먼저 안내한다.
- **탈퇴와 이용 제한**: 설정에서 이메일+비밀번호로 탈퇴. 악의적 접근·자동화된 남용은 제한할 수 있고, 가능한 범위에서 사유와 문의 방법을 안내한다. 법정 권리와 운영자 책임을 일괄 배제하지 않는다.
- **분쟁**: 대한민국 법령에 따르며 이용자의 법정 권리를 제한하지 않는다.

## 계정 메일

| 메일 | 언제 | 링크 |
|---|---|---|
| 이메일 주소 확인 | 가입, 이메일 변경, 다시 보내기 | `/verify?token=…`, 3일 |
| 비밀번호 재설정 | 로그인 화면 '비밀번호를 잊었어요' | `/reset?token=…`, 30분·한 번, 바꾸면 다른 기기 로그아웃 |

- 보내는 주소 `harukan <no-reply@leneu.store>`(Resend). HTML(표로 그린 로고·버튼)과 글자 버전을 함께 보낸다(`server/mail.mjs`).
- 비밀번호 찾기는 가입 여부와 상관없이 같은 응답을 준다(가입 여부 노출 방지). 발송 실패는 서버 로그 `[mail] failed`에만 남긴다.
