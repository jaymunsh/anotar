# 공개 운영 정보와 확정할 내용

작성: 2026-10-11, 갱신: 2026-10-12, 2026-10-18(harukan 이름·이메일 계정·발신 메일). 사용자 답변과 실제 운영 확인에 근거한다.

## 확인된 사실

| 항목 | 값 |
|---|---|
| 서비스명 | harukan(하루칸). 예전 이름 anotar 플래너 |
| 운영 형태 | 개인 운영 |
| 운영자·개인정보 담당 | 문성혁 |
| 공개 문의처 | support@leneu.store |
| 계정 | 이메일 + 닉네임 + 비밀번호 |
| 적용 주소 | 새 플래너 leneu.store, 기존 개인 Anotar personal.leneu.store |
| 서버 저장 위치 | Oracle 일본 오사카 (ap-osaka-1) |
| 정책 시행일 | 2026-10-12 최초. 개정판(약관 버전 `2026-10-18`)은 서버 반영일을 `LEGAL_PUBLISHED_AT`으로 |
| 언어 | 한국어/영어, 브라우저에 선택 저장 |
| 결제 | 이번 구현 없음 |
| 광고·추적 SDK·외부 AI·기록 공개 | 이번 구현 없음 |
| 발신 메일 | Resend(미국 법인, 발송 지역 도쿄), `no-reply@leneu.store`, 이메일 확인·비밀번호 재설정만. 받는 주소와 메일 내용(링크)을 전달 |

전달받을 Gmail은 운영 설정 정보로만 다룬다. 공개 푸터·정책에 개인 Gmail 주소를 노출하지 않는다. 사업자등록번호, 사업장 주소, 회사 이름은 제공받지 않았으므로 만들어 넣지 않는다. 개인 운영과 법인 사이트를 혼동시키지 않는다.

## 운영에 반영한 내용

1. **서버 지역**: Oracle 콘솔의 Osaka/ap-osaka-1에서 같은 인스턴스에 별도 서비스를 배포했다. 호스팅 지역·정책 시행일을 운영 `/api/site`로 다시 확인했다.
2. **제공자 설명**: Oracle 서버·백업 저장, Cloudflare 글로벌 보안 연결·메일 라우팅, Google Gmail 문의 보관을 업체·위치·항목·목적·기간·공식 연락처 링크와 함께 명시했다. 글로벌 네트워크의 실제 처리 위치가 경로에 따라 달라짐을 설명했다. 개별 계약에 관한 별도의 법적 인증을 수행한 것으로 표기하지 않는다.
3. **백업**: 매일04:30 한국시간 timer 활성, 실제 온라인 백업600·디렉터리700·임시 경로 복원 확인. 7일 지난 사본은 다음 실행 때 제거한다. 최소 탈퇴 기록은 무작위 ID와 시각만 8일 보관하고 복원에 적용한다.
4. **문의 보관**: 처리 완료 후1년을 초기 정책과 운영 정리 기준으로 정했다. 자동 메일 삭제 기능은 구현하지 않았다. 운영자 문성혁이 정리와 권리 요청 처리를 담당한다.
5. **로그**: 앱은 요청 본문·비밀번호 원문을 로그로 남기지 않는다. 제공자의 네트워크·보안 로그는 제공자 정책에 따른다고 명시했다. 제공자 자체 로그를 앱이 삭제하거나 보존 상한을 강제한다고 주장하지 않는다.
6. **메일**: 사용자가 Gmail 목적지를 인증했고 support 전달 규칙이 Active인 것을 읽어 확인했다. 실제 전달 수신은 아직 시험하지 않았다.
7. **정책/가입**: `LEGAL_PUBLISHED_AT=2026-10-12`, `LEGAL_REVIEWED=true`, `REGISTRATION_ENABLED=true`를 적용했다. 이 플래그는 실제 사실을 반영한 게시 상태이며 법적 적합성 보증이 아니다.

## 2026-10-18 정리 (서버 반영 때 적용)

- harukan 출시는 **운영 데이터를 비우고 새로 시작**한다. 그래서 개정 이력·재동의·예전 아이디 계정 안내를 문서에 두지 않는다. 약관 버전은 `2026-10-18`(접미사 없음), 시행일은 서버 반영일을 `LEGAL_PUBLISHED_AT`으로.
- 처리방침: 이메일·닉네임·이메일 확인 시각, 메일 링크 해시(확인 3일·재설정 30분), Resend 위탁, 파기 대상에 메일 링크·메모·목표와 계획.
- 약관: 이메일·닉네임·비밀번호 가입, 서비스 범위에 목표·회고, 탈퇴는 이메일+비밀번호 확인.
- 아이디 로그인·복구코드(`/recover`)는 제거했다. 로그인·재설정·탈퇴 확인은 이메일만 쓴다.

## 운영자가 이어서 확인할 항목

- 다른 메일함에서 `support@leneu.store`로 보내 지정된 수신함에 도착하는지 확인한다.
- support 주소로 답장·발신하려면 발신 제공자/SMTP 설정이 추가로 필요하다. 현재는 수신 전달만 활성이다.
- 문의 완료일을 관리하고1년이 지난 메일을 삭제한다. 개인정보 권리 요청은 본인 확인 후 처리한다.
- 사업자·주소·새 연락처, 유료 결제, 새 제공자·처리 지역·보유 기간이 생기면 운영자 소개·정책·약관을 갱신한다.
