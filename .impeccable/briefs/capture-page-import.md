# 메모 상세 → 페이지에 담기

모드: Operate. 기존 leneu. 화면 체계를 확장한다. 새로운 시각 세계나 합성 이미지를 만들지 않는다.

- THESIS: 먼저 보관한 메모에서 필요한 내용을 고르고, 사용자가 관리하는 문서로 옮겨 정리한다.
- OWN-WORLD: DESIGN.md의 종이·숲색 라이트와 차콜·세이지 다크, 기존 글꼴·8px 컨트롤·작은 문서 도구를 유지한다.
- STORY: 메모 상세의 명시적 동작 → 기존/새 페이지와 계층 경로 선택 → 내용·첨부 선택 → 담기 → 해당 문서에서 즉시 편집.
- FIRST VIEWPORT: 상세 패널 안에서 화면을 전환한다. 제목·뒤로 가기, 두 목적지 탭, 제목 검색·목록, 내용·첨부 선택, 아래의 확인 버튼이 있다. 휴대폰에서는 화면 폭을 사용하고 확인 버튼은 아래에 남는다.
- FORM: 일반 메모 카드와 분리된 작은 선택 목록, 한 줄 제목·상위 경로, 선택 상태, 실제 체크박스. 출처 카드는 유형·한국 시각·한 줄 미리보기·첨부 수를 표시한다.

## 사실과 범위

원문과 파일 바이트는 보존한다. 가져온 사본을 편집할 수 있다. 실패 시 선택을 보존하고 응답 유실·새로고침 재시도는 같은 작업을 확인한다. AI·URL 수집·페이지 직접 업로드·공개 공유·페이지 간 블록 분배는 이번 범위에 없다.

## 검증 뷰포트

1327×1000, 390×1000, 320×1000. 각각 light/dark의 선택 화면과 문서 화면을 `.impeccable/review/page-connections/`에 저장한다. 코드로 구현했으며 승인된 이미지 컴프는 없다.
