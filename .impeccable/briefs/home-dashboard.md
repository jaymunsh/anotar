# 입력함 대시보드

2026-09-30. 기존 Operate 화면 `/`의 승인된 확장이다.

## 목적

메모를 빠르게 저장하고, 막 기록한 내용·할 일·AI 처리·정리한 페이지를 첫 화면에서 함께 확인한다. PC와 모바일 모두 실제 항목을 보여주며 모바일에서는 별도 시트를 열지 않고 곧바로 입력한다.

## Direction contract

**THESIS:** 입력을 우선하면서 작업 현황과 최근 기록을 한눈에 이어 보는 개인 대시보드.

**OWN-WORLD:** 기존 종이·숲색 / 차콜·세이지, DM Sans·Noto Sans KR, 얇은 경계와 작은 조작을 이어 쓴다. 전역 팔레트·서체·데이터 모델은 바꾸지 않는다.

**STORY:** 떠오른 생각을 입력하고 저장한다. 진행 중 AI 요청과 할 일을 확인하고, 최근 메모에서 원본을 열거나 최근 페이지에서 정리한 문서로 이동한다.

**FIRST VIEWPORT:** PC에서는 짧은 제목 아래 왼쪽에 입력·최근 메모·최근 페이지, 오른쪽에 할 일·AI 현황을 둔다. 모바일에서는 이어서 작업하기 다음에 작은 인라인 입력·AI 현황·할 일·최근 메모·최근 페이지를 세로로 둔다. 전체 화면 입력은 `크게 쓰기`로 선택한다.

**DESKTOP DENSITY:** 1101px 이상에서 제목·모듈 사이와 카드 안쪽 여백을 좁히고 입력 본문을 56px부터 세로로 늘릴 수 있게 둔다. 최근 메모·페이지 행과 할 일·AI 패널도 함께 조밀하게 맞춘다. 모바일의 입력·터치 크기는 유지한다.

**WIDE SCREENS:** 홈 본문은 최대 1160px로 가운데에 두고, 두 열과 카드가 대형 모니터 폭만큼 계속 늘어나지 않게 한다.

**GROUPING:** 보조 열은 304px로 고정하고 최근 메모는 하나의 12px 목록 표면 안에 구분선으로 나눈다. 소개 오른쪽 검색 버튼은 기존 통합 검색을 연다.

**FORM:** 기존 컴포넌트와 테마 변수를 재배치한 코드 기반 refinement. 새로운 시각 세계나 예시 통계·이미지를 만들지 않는다.

## 구현 계약

- Capture·Task·AI 컴포넌트의 상태와 저장·초안 계약을 재사용한다. 모바일 홈의 중복 하단 도크만 숨기고 다른 경로의 도크는 유지한다.
- 일반 저장은 `저장`, AI 체크 시에는 `저장하고 AI 요청`이다. URL 붙여넣기·이미지/파일 첨부·전체 화면 작성 동선을 보존한다.
- 최근 페이지 최대 4개는 사이드바와 같은 PageWorkspace 목록 메타데이터를 재사용한다. 홈에서 문서 전체나 편집기·Mermaid를 먼저 불러오지 않는다.
- 1920px·1327px PC와 390px·320px 모바일의 라이트·다크 화면을 검증한다. 긴 제목·본문은 좁은 폭에서 말줄임표로 표시하고 실제 항목을 가로로 넘기지 않는다.

## 2026-10-02 작업 화면 가독성

목록 본문은 14px, 날짜·유형은 12px를 기준으로 한다. 조밀한 44px 상단바와 304px 보조 열을 유지한다. 최근 페이지는 14px 제목과 날짜가 있는 56px 이하 행이다. 메모 행은 실제 capture-row 경계로 구분하고 좁은 화면에서도 한 줄 말줄임을 유지한다. AI는 요청 내용 → 유형/상태 → 결과·진행·오류 확인 순서이며, 클릭은 기존 정확한 작업 링크를 사용한다.

## 2026-10-04 입력까지의 거리

모바일 최근 열람·즐겨찾기는 각 그룹의 한 줄 가로 스크롤로 보여준다. 링크는 44px 터치 높이, 최대 260px이며 긴 제목은 말줄임과 접근성 이름으로 유지한다. 키보드 초점과 일반 가로 스크롤을 지원하고 페이지 자체는 가로로 넘치지 않는다. PC의 두 열·입력/할 일 상단 정렬은 그대로다. 홈 입력 표면은 목록과 같은 12px 모서리와 얇은 경계만 사용한다. 소개 문장에는 명시적인 8px 위 여백·1.6 행간을 둔다.
