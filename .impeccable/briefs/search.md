# 통합검색

Mode: Operate. 기존 페이지 빠른 찾기를 메모·AI 요청·페이지 본문·파일명 검색으로 확장한다.

## 방향

leneu.의 현재 paper/forest 및 charcoal/sage 팔레트, 한국어 글꼴, 작은 도구 줄과 말줄임표를 계승한다. 검색어·분류·현재 결과를 즉시 읽고 원문으로 이동하는 데 집중한다. 검색 입력은 키보드 초점을 유지하고 방향키로 선택한 행이 보이도록 스크롤한다.

## 첫 화면

680px 이하의 팔레트에 44px 입력/닫기, 간결한 분류 줄, 최근 활성 기록을 표시한다. 각 행은 유형/출처와 한 줄 원문·짧은 일치 부분을 제공한다. 모바일에는 12px 여백과 뷰포트 안의 결과 스크롤을 사용한다. 본문·원문 대비는 기존 토큰을 따르며 기계적인 구현 용어는 사용자 화면에 표시하지 않는다.

## 상태와 확인

빈 입력 최근 기록, 두 글자 미만 안내, 로딩, 결과 없음, 조회 실패/재시도, 더 보기와 변경 리셋을 구분한다. 한글 조합 중 요청/Enter를 보류하며 이전 응답은 적용하지 않는다. Escape는 검색만 닫고 입력/페이지 초안과 초점을 보존한다. 320·390·1327px 라이트/다크 캡처와 44px 조작 영역을 확인한다.
